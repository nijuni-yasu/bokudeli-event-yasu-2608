# grill-me（実装前の設計インタビュー）

出典: [mattpocock/skills の grill-me](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md)（外部スキルを日本語化し、本プロジェクト向けに加筆）。

この計画のあらゆる側面について、私たちが共通理解に達するまで徹底的に質問する。設計ツリーの各枝をたどり、決定事項間の依存関係を1つずつ解決していく。それぞれの質問に対して、推奨する回答を必ず提示する。

質問は必ず1つずつ行う。

コードベースを調べることで疑問が解決できるのであれば、先にコードベースを調べる。

## 進め方

1. 最初にコードベースを調査し、既存の設計・スキーマ・関連コードを把握する
2. 設計ツリーの根（最も依存関係の上流にある決定）から順に、1問ずつ質問する
3. 各質問では選択肢と「推奨回答」を提示し、ユーザーが「はい」で進められるようにする
4. ユーザーの回答に応じて方向性を調整する（受け身の同意を促さない）
5. 全分岐が解決したら、最終的な設計の全体像をまとめて提示する

## 注意点

- これは面接ではなく会話である。ユーザーがどこに向かうかを決め、会話をリードできるよう促す
- 低忠実度な質問（URL・データ構造など、プロトタイプ無しで答えられる問い）を優先する
- レイアウトなど高忠実度な質問が必要になったら、一旦中断してプロトタイプ作成を提案する（ハンドオフ）
- スコープが広すぎる場合は、まずタスク分解を提案し、分解後の単位ごとに本スキルを使う
- 設計フェーズのやりとりは実装フェーズのコンテキストとして引き継ぐ。大規模な場合は documents/ にドキュメントとして保存する
- 出力は日本語で行う
