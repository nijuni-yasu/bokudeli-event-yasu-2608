### 0-2. user / partner のテスト基盤（最低限）

**設計上の制約（レビュー反映）**: `user` / `partner` は `common` / `base` と異なり **auto-import（ref/computed 等の自動注入）・alias（`@` `@core` 等）・vuetify プラグインに強く依存**する。素の vitest ではこれらが解決されず `.vue` やコンポーネントのテストは即失敗するため、**テスト対象は auto-import・vuetify 非依存の純粋ロジックに限定**する（`router/utils.ts` / `navigation/utils.ts` 等）。環境は `base` 同様 **node** のままとし、jsdom / `@vue/test-utils` はコンポーネントテストが必要になってから導入する。

| ID | タスク | 詳細 | Owner | 状態 |
|:---|:-------|:-----|:------|:-----|
| 0-2-1 | vitest 設定追加 | `user` / `partner` に `vitest.config.ts` を追加（`environment: node`・`test.include: ['src/**/*.test.ts']`・`vite.config.ts` と同じ `resolve.alias` を引き継ぐ） | nijuni-yasu | ✅ DONE |
| 0-2-2 | vitest 依存追加 | 両 `package.json` の devDependencies に `vitest`（既存と同じ `^3.0.5`）を追加（hoisting 依存を避け明示する） | nijuni-yasu | ✅ DONE |
| 0-2-3 | test スクリプト | 両 `package.json` に `"test": "vitest run"` を追加 | nijuni-yasu | ✅ DONE |
| 0-2-4 | スモークテスト | 各 1 件の最小テストを追加（空振り防止）。**対象は純粋ロジックに限定（`.vue`・auto-import 依存は対象外）** | nijuni-yasu | ✅ DONE |
| 0-2-5 | CI 反映 | CI の対象に `user` / `partner` を追加。**vitest だけでなく `lint` と `build:types`（vue-tsc）も同時に追加**し、テストだけ走り lint・型が素通りする状態を避ける。直列実行で `timeout-minutes` が逼迫する場合は延長または job 分割（matrix）を検討 | nijuni-yasu | ✅ DONE |
