# イベント繰り返し作成機能

## 1. 概要
### 1.1 機能の目的
既存イベントを指定した繰り返し条件で簡単に複製し、定期開催イベントの作成工数を削減する。

### 1.2 主要な機能
- 「イベント繰り返し作成」ボタンの設置（イベント新規作成ボタンの隣）
- 既存イベントの選択とコピー元指定
- カスタム繰り返し条件（間隔・曜日・終了条件）の設定
- 条件に従ったイベントの一括複製
- 作成イベントは独立管理
- 取り消し不可のため確認ダイアログ表示

### 1.3 対象ユーザー
- イベント主催者
- コミュニティ管理者

## 2. ねらい
### 2.1 ビジネス目標
- 主催者のイベント作成工数削減
- 定期開催イベント数の増加
- 主催者の継続利用率向上

### 2.2 ユーザー価値
- 定期イベント作成の手間を大幅に削減
- ミスや漏れの防止
- 柔軟な繰り返し設定による利便性向上

### 2.3 成功指標（KPI）
- 繰り返し作成機能の利用回数
- 定期イベントの作成数
- 主催者のアクティブ率

## 3. 前提条件
### 3.1 技術的前提条件
- イベントデータの複製処理が可能であること
- UIコンポーネント（DatePicker, Select, RadioGroup等）が利用可能

### 3.2 ビジネス的前提条件
- 主催者が複数イベントを管理できること

### 3.3 依存関係
- イベント作成・編集機能
- コミュニティ管理画面

## 4. 画面仕様
### 4.1 画面遷移
1. 「イベント繰り返し作成」ボタン押下
2. コピー元イベント選択モーダル表示
3. カスタム繰り返し設定モーダル表示
4. 「完了」押下で確認ダイアログ
5. 実行後、イベント一覧に複製イベントが追加

### 4.2 UI要素
- 「イベント繰り返し作成」ボタン（`user/src/componentsLocal/manage/community/events.vue`）
- コピー元イベント選択リスト
- 繰り返し間隔（数値＋単位選択：日/週/月/年）
- 曜日選択（週ごと選択時のみ）
- 終了条件（終了日 or 回数）
- 完了・キャンセルボタン
- 確認ダイアログ

## 5. 技術仕様・データ構造設計
### 5.1 Firestoreスキーマ
```typescript
// 既存イベントスキーマを流用。複製時は新規IDで保存。
// 追加で「複製元イベントID」や「繰り返し条件」などの履歴を残す場合は下記例
{
  id: string,
  title: string,
  ... // 既存イベント項目
  originalEventId?: string, // 複製元イベントID（任意）
  createdByRepeat?: boolean, // 繰り返し作成フラグ
  repeatSetting?: {
    interval: number,
    unit: 'day' | 'week' | 'month' | 'year',
    daysOfWeek?: number[], // 週ごとの場合
    endType: 'date' | 'count',
    endValue: string | number,
  }
}
```

### 5.2 Functions設計
#### 5.2.1 Callable Functions
- `repeatCreateEvents`: イベント繰り返し作成
  - **引数**: 
    - `originalEventId: string`
    - `repeatSetting: {interval: number, unit: string, daysOfWeek?: number[], endType: string, endValue: string|number}`
  - **戻り値**: 作成イベントIDリスト
  - **認証**: 主催者のみ

#### 5.2.2 Trigger Functions
- なし（複製は明示的な操作のみ）

#### 5.2.3 Scheduled Functions
- なし

### 5.3 処理フロー
1. 「イベント繰り返し作成」ボタン押下
2. コピー元イベント選択
3. 繰り返し条件入力
4. 「完了」押下で確認ダイアログ
5. Callable Function呼び出し
6. 条件に従いイベントを複製（各イベントは独立IDで保存）
7. 完了後、イベント一覧をリロード

- イベント一覧の表示件数増加に注意
