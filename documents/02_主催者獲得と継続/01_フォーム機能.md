# フォーム機能

## 1. 概要
### 1.1 機能の目的
主催者獲得施策として、イベント参加者からの事前情報収集を実現し、ビジネスイベントとして効果的に実施するためのフォーム機能を提供する。

### 1.2 主要な機能
- コミュニティ管理者は、コミュニティ管理画面でフォームを作成・編集する
- コミュニティ管理者は、イベント作成時に、事前に作成したフォームを一覧から選択して、イベントに設定する
- イベント参加者は、注文時にフォーム回答を実施
- コミュニティ管理者は、フォーム回答内容を確認・ダウンロード可能
- フォームテンプレート機能

### 1.3 対象ユーザー
- コミュニティ管理者（フォーム作成・管理）
- イベント参加者（フォーム回答）
- システム管理者（フォーム機能の監視・運用）

### 1.4 フォーム項目タイプ
| タイプ | 変数名 | 説明 | バリデーション | オプション |
|--------|------------|------|----------------|------------|
| テキストボックス | `text` | 1行テキスト入力 | 最大文字数、必須チェック | プレースホルダー、デフォルト値 |
| テキストエリア | `textarea` | 複数行テキスト入力 | 最大文字数、必須チェック | 行数指定、プレースホルダー |
| メールアドレス | `email` | メールアドレス入力 | メール形式、必須チェック | プレースホルダー |
| 電話番号 | `phone` | 電話番号入力 | 電話番号形式、必須チェック | プレースホルダー |
| 日付 | `date` | 日付選択 | 日付範囲、必須チェック | 最小日付、最大日付 |
| チェックボックス | `checkbox` | 複数選択 | 選択数制限 | 選択肢配列 |
| ラジオボタン | `radio` | 単一選択 | 必須チェック | 選択肢配列 |
| ドロップダウン | `select` | 単一選択 | 必須チェック | 選択肢配列 |
<!-- | ファイルアップロード | `file` | ファイル添付 | ファイルサイズ、形式制限 | 許可形式、最大サイズ | -->

## 2. ねらい
### 2.1 ビジネス目標
- 主催者獲得率の向上（目標：20%向上）
- イベント参加者の事前情報収集率向上（目標：80%以上）
- ビジネスイベントの質向上
- 参加者満足度の向上

### 2.2 ユーザー価値
- **主催者**: 参加者の事前情報を把握し、より効果的なイベント運営が可能
- **参加者**: イベント参加前に必要な情報を提供し、スムーズな参加体験
- **管理者**: フォーム機能を通じた主催者サポートの向上

### 2.3 成功指標（KPI）
- フォーム作成数（月間）
- フォーム回答率（イベント別）
- 主催者満足度（フォーム機能利用後）
- 参加者情報収集精度の向上

## 3. 前提条件
### 3.1 技術的前提条件
- 既存のFirebase（Firestore, Storage, Functions）インフラ
- Vue 3 + TypeScript + Vuetify環境
- 既存のコミュニティ・イベント・注文システム
- VeeValidate 3.x（フォームバリデーション）

### 3.2 ビジネス的前提条件
- コミュニティ管理者権限を持つユーザーのみフォーム作成可能
- イベント参加者は注文時にフォーム回答が必要
- フォーム回答は注文完了前に行う必要がある

### 3.3 依存関係
- 既存のコミュニティ管理機能
- 既存のイベント管理機能
- 既存の注文システム
- Firebase Storage（ファイルアップロード用）

  - カラー: プライマリ

interface FormDoc {
  // 必須フィールド
  form_id: string;                    // フォームID（ドキュメントID）
  form_name: string;                  // フォーム名（必須、最大100文字）
  form_contents: FormField[];         // フォーム項目配列（必須）
  created_at: Timestamp;              // 作成日時（必須）
  updated_at: Timestamp;              // 更新日時（必須）
  created_by: string;                 // 作成者ID（必須）
  updated_by: string;                 // 更新者ID（必須）
  is_deleted: boolean;                // 削除フラグ（必須、デフォルト: false）
  
  // オプションフィールド
  form_description?: string;          // フォーム説明（任意、最大500文字）
  settings?: FormSettings;            // フォーム設定（任意）
}

interface FormField {
  field_id: string;                   // 項目ID（必須、自動生成）
  field_name: string;                 // 項目名（必須、最大50文字）
  field_type: FormFieldType;          // 項目タイプ（必須）
  is_required: boolean;               // 必須フラグ（必須）
  display_order: number;              // 表示順序（必須）
  
  // オプションフィールド
  field_description?: string;         // 項目説明（任意、最大200文字）
  validation?: ValidationRule;        // バリデーション設定（任意）
  options?: FieldOption[];            // 選択肢（任意、チェックボックス、ラジオ、ドロップダウン用）
  conditional_logic?: ConditionalLogic; // 条件分岐設定（任意）
}

interface FormSettings {
  response_deadline?: Timestamp;      // 回答期限（任意）
  allow_multiple_responses: boolean;  // 複数回答許可（必須、デフォルト: false）
  anonymous_responses: boolean;       // 匿名回答設定（必須、デフォルト: false）
  show_results_to_participants: boolean; // 参加者への結果表示（必須、デフォルト: false）
  max_file_size?: number;            // 最大ファイルサイズ（MB）（任意）
  allowed_file_types?: string[];     // 許可ファイル形式（任意）
}

interface FormResponseDoc {
  // 必須フィールド
  response_id: string;                // 回答ID（ドキュメントID）
  form_id: string;                    // フォームID（必須）
  order_id: string;                   // 注文ID（必須）
  user_id: string;                    // ユーザーID（必須）
  responses: FormResponse[];          // 回答内容配列（必須）
  created_at: Timestamp;              // 回答日時（必須）
  updated_at: Timestamp;              // 更新日時（必須）
  is_completed: boolean;              // 完了フラグ（必須）
  
  // オプションフィールド
  completed_at?: Timestamp;           // 完了日時（任意）
  is_anonymous?: boolean;             // 匿名回答フラグ（任意）
}

interface FormResponse {
  field_id: string;                   // 項目ID（必須）
  response_value: any;                // 回答内容（必須）
  response_datetime: Timestamp;       // 回答日時（必須）
  
  // オプションフィールド

}

export class Form {
  form_id: string = '';
  community_id: string = '';
  form_name: string = '';
  form_description?: string;
  form_contents: FormField[] = [];
  settings?: FormSettings;
  created_at: Date = new Date();
  updated_at: Date = new Date();
  created_by: string = '';
  updated_by: string = '';
  is_deleted: boolean = false;
  
  // バリデーション
  validate(): boolean {
    return this.form_name.length > 0 && 
           this.form_name.length <= 100 &&
           this.form_contents.length > 0;
  }
  
  // ファクトリメソッド
  static fromDb(data: any): Form {
    const form = new Form();
    form.form_id = data.form_id;
    form.form_name = data.form_name;
    form.form_description = data.form_description;
    form.form_contents = data.form_contents || [];
    form.settings = data.settings;

    form.updated_at = data.updated_at.toDate();
    form.created_by = data.created_by;
    form.updated_by = data.updated_by;
    form.is_deleted = data.is_deleted || false;
    return form;
  }

  user_id: string = '';

  // フォーム一覧取得
  const getForms = async (communityId: string) => {
    const snapshot = await db
      .collection('communities')
      .doc(communityId)
      .collection('forms')
      .where('is_deleted', '==', false)

export const createForm = onCall(async (request) => {
  const uid = request.auth?.uid
  if (uid == null) {
    throw new HttpsError('unauthenticated', '認証が必要です')
  }
  
  const { communityId, formName, formDescription, formContents, settings } = request.data
  
  // バリデーション
  if (!communityId || !formName || !formContents) {
    throw new HttpsError('invalid-argument', '必須パラメータが不足しています')
  }
  
  // コミュニティ管理者権限チェック
  const community = await db.collection('communities').doc(communityId).get()
  if (!community.exists || !community.data()?.managers?.includes(uid)) {
    throw new HttpsError('permission-denied', 'コミュニティ管理者権限が必要です')
  }
  
  // フォーム作成
  const formRef = db.collection('communities').doc(communityId).collection('forms').doc()
  const form = {
    form_id: formRef.id,
    form_name: formName,
    form_description: formDescription,
    form_contents: formContents,
    settings: settings || {},
    created_at: new Date(),
    updated_at: new Date(),
    created_by: uid,
    updated_by: uid,
    is_deleted: false,
  }
  
  await formRef.set(form)
  
  return {
    success: true,
    form_id: formRef.id,
    form: form
  }
})

export const submitFormResponse = onCall(async (request) => {
  const uid = request.auth?.uid
  if (uid == null) {
    throw new HttpsError('unauthenticated', '認証が必要です')
  }
  
  const { communityId, eventId, formId, responses, isAnonymous } = request.data
  
  // バリデーション
  if (!communityId || !eventId || !formId || !responses) {
    throw new HttpsError('invalid-argument', '必須パラメータが不足しています')
  }
  
  // フォーム存在チェック
  const formDoc = await db.collection('communities').doc(communityId).collection('forms').doc(formId).get()
  if (!formDoc.exists) {
    throw new HttpsError('not-found', 'フォームが見つかりません')
  }
  
  // イベント存在チェック
  const eventDoc = await db.collection('communities').doc(communityId).collection('events').doc(eventId).get()
  if (!eventDoc.exists) {
    throw new HttpsError('not-found', 'イベントが見つかりません')
  }
  
  // 回答作成
  const responseRef = db.collection('communities').doc(communityId).collection('events').doc(eventId).collection('form_responses').doc()
  const formResponse = {
    response_id: responseRef.id,
    form_id: formId,
    user_id: uid,
    responses: responses,
    created_at: new Date(),
    updated_at: new Date(),
    is_completed: true,
    completed_at: new Date(),
    is_anonymous: isAnonymous || false,
  }
  
  await responseRef.set(formResponse)
  
  return {
    success: true,
    response_id: responseRef.id
  }
})

### 5.7 処理フロー
#### 5.7.1 フォーム作成フロー
1. コミュニティ管理者がフォーム作成画面でフォーム情報を入力
2. フロントエンドでバリデーション（フォーム名、項目設定）
3. Callable Function `createForm`を呼び出し
4. Firebase Functionで認証チェック
5. コミュニティ管理者権限チェック
6. フォーム作成処理実行
7. レスポンスをフロントエンドに返却
8. フロントエンドでフォーム一覧画面に遷移

#### 5.7.2 フォーム回答フロー
1. イベント参加者が注文フローでフォーム回答画面に到達
2. フロントエンドでフォーム項目を表示
3. 参加者が各項目に回答を入力
4. リアルタイムバリデーション実行
5. 一時保存ボタンで回答内容を保存
6. 必須項目完了後に次へボタンが有効化
7. 回答確認画面で内容確認
8. Callable Function `submitFormResponse`を呼び出し（communityId, eventId, formId, responses, isAnonymous）
9. Firebase Functionで認証・バリデーション
10. フォーム回答を保存（イベントのサブコレクションに保存）
11. Trigger Function `onFormResponseCreated`が自動実行
12. 注文確認画面に遷移

- **新規サブコレクション**: `/communities/{communityId}/forms/{formId}`（フォーム定義管理）、`/communities/{communityId}/events/{eventId}/form_responses/{responseId}`（フォーム回答管理）

- **既存機能**: イベント作成・注文フローへの影響なし
