# イベントページの作成の初期値

## 1. 概要
### 1.1 機能の目的
イベント作成時の初期値を設定することで、主催者の入力負担を軽減し、イベント作成の完了率を向上させる。

### 1.2 主要な機能
- イベント名（`event_name`）にコミュニティ名を基にした初期値を設定
- イベントカバー画像（`event_cover_url`）にコミュニティカバー画像を初期値として設定
- イベント説明（`event_desc`）にコミュニティ名を基にした初期値を設定

### 1.3 対象ユーザー
- イベント主催者（コミュニティ管理者）

## 2. ねらい
### 2.1 ビジネス目標
- イベント作成の完了率を向上させる
- イベント作成時の入力負担を軽減し、主催者の離脱を防ぐ
- イベント作成フローのUXを改善する

### 2.2 ユーザー価値
- イベント作成時の入力項目が減り、作成が容易になる
- コミュニティ情報を基にした初期値により、一貫性のあるイベント情報を簡単に設定できる
- カバー画像の設定が自動化され、画像選択の手間が省ける

### 2.3 成功指標（KPI）
- イベント作成完了率の向上
- イベント作成画面での離脱率の低下
- イベント作成にかかる時間の短縮

## 3. 前提条件
### 3.1 技術的前提条件
- コミュニティ情報（`community_name`, `community_cover_image_url`）が取得可能であること
- イベント作成画面でコミュニティ情報にアクセスできること
- 既存のイベント作成フローが動作していること

### 3.2 ビジネス的前提条件
- コミュニティが作成済みであること
- コミュニティにカバー画像が設定されていること（任意）

### 3.3 依存関係
- コミュニティ情報取得機能（`useCommunityStore`）
- イベント作成機能（`base/src/components/EventEdit.vue`）
- イベントスキーマ（`common/src/schemas/Event.ts`）

## 4. 画面仕様
### 4.1 画面遷移
イベント作成画面（`user/src/pages/manage/community/[communityAccount]/newevent.vue`）で、新規イベント作成時に初期値が自動設定される。実際のイベント作成ロジックは`base/src/components/EventEdit.vue`コンポーネントで実装される。

### 4.2 UI要素
#### 4.2.1 入力フィールド
- **イベント名（`event_name`）**
  - 必須項目
  - 初期値: `"[コミュニティ名]のイベント"`
  - ユーザーが編集可能

- **イベントカバー画像（`event_cover_url`）**
  - 必須項目
  - 初期値: コミュニティカバー画像（`community_cover_image_url`）
  - ユーザーが画像を変更可能

- **イベント説明（`event_desc`）**
  - 任意項目
  - 初期値: `"[コミュニティ名]のイベント"`
  - ユーザーが編集可能

#### 4.2.2 ボタン・アクション
- 既存のイベント作成フローに影響なし
- 初期値は自動設定され、ユーザー操作は不要

#### 4.2.3 表示要素
- 初期値が設定された状態でイベント作成画面が表示される
- ユーザーは初期値をそのまま使用するか、編集することができる

### 5.2 Firestoreフロントエンド処理
- **データ取得処理**: コミュニティ情報を取得し、初期値を設定
  ```typescript
  // base/src/components/EventEdit.vue
  const communityStore = useCommunityStore(props.communityAccount) as CommunityStore
  
  // Initialize _event when community data becomes available
  watch(
    () => communityStore.community,
    (community) => {
      if (props.eventId == null && _event.value == null && community != null) {
        _event.value = new BokudeliEvent(community.community_id, null, {
          community_id: community.community_id,
          community_name: community.community_name,
          community_account: community.community_account,
          organizer_fullname: community.community_manager_fullname,
          organizer_company: community.community_company,
          organizer_email: community.community_email,
          organizer_phone_company: community.community_phone,
          // 初期値の設定（新規追加）
          event_name: `${community.community_name}のイベント`,
          event_cover_url: community.community_cover_image_url ?? '',
          event_desc: `${community.community_name}のイベント`,
        })
      }
    },
    { immediate: true },
  )
  ```
- **データ更新処理**: 既存のイベント更新処理を使用（変更なし）
- **リアルタイム監視**: 既存の監視処理を使用（変更なし）
- **エラーハンドリング**: 
  - コミュニティ名が取得できない場合: `event_name`と`event_desc`は空文字列
  - コミュニティカバー画像が存在しない場合: `event_cover_url`は空文字列
  - 既存のエラーハンドリング処理を使用

### 5.3 Firestoreセキュリティルール

### 5.4 Firestoreインデックス設計

### 5.5 Functions設計

### 5.6 処理フロー
#### 5.6.1 イベント作成時の初期値設定フロー
```markdown
### イベント作成時の初期値設定フロー
1. ユーザーがイベント作成画面にアクセス（`user/src/pages/manage/community/[communityAccount]/newevent.vue`）
2. `EventEdit`コンポーネント（`base/src/components/EventEdit.vue`）が読み込まれる
3. コミュニティ情報を取得（`useCommunityStore`）
4. 新規イベント作成の場合（`props.eventId == null`）
   - コミュニティ情報が取得できたら、`watch`で`BokudeliEvent`を初期化
   - コミュニティ基本情報を設定
     - `community_id`
     - `community_name`
     - `community_account`
     - `organizer_fullname`（`community_manager_fullname`から）
     - `organizer_company`（`community_company`から）
     - `organizer_email`（`community_email`から）
     - `organizer_phone_company`（`community_phone`から）
   - 初期値を設定（新規追加）
     - `event_name = "[コミュニティ名]のイベント"`
     - `event_cover_url = community_cover_image_url`（存在しない場合は空文字列）
     - `event_desc = "[コミュニティ名]のイベント"`
5. イベント作成画面に初期値が設定された状態で表示
6. ユーザーが初期値を編集するか、そのまま使用
7. イベント保存処理（既存の処理を使用）
```

#### 5.6.2 エラーハンドリングを含む処理フロー
```markdown
### イベント作成時の初期値設定フロー（エラーハンドリング含む）
1. ユーザーがイベント作成画面にアクセス（`user/src/pages/manage/community/[communityAccount]/newevent.vue`）
2. `EventEdit`コンポーネント（`base/src/components/EventEdit.vue`）が読み込まれる
3. コミュニティ情報を取得（`useCommunityStore`）
   - 成功: 処理を継続
   - 失敗: エラーメッセージを表示して処理を停止
4. 新規イベント作成の場合（`props.eventId == null`）
   - コミュニティ情報が取得できたら、`watch`で`BokudeliEvent`を初期化
   - コミュニティ基本情報を設定
   - 初期値を設定
     - `event_name`: コミュニティ名が取得できない場合は空文字列
     - `event_cover_url`: コミュニティカバー画像が存在しない場合は空文字列（`?? ''`で処理）
     - `event_desc`: コミュニティ名が取得できない場合は空文字列
5. イベント作成画面に初期値が設定された状態で表示
6. ユーザーが初期値を編集するか、そのまま使用
7. イベント保存処理
   - 成功: イベント作成完了
   - 失敗: エラーメッセージを表示
```

- 既存のイベントスキーマに変更はない
- 新規フィールドの追加はない

#### 8.1.2 アプリケーションへの影響
