## 1. 目的

企業・幹事向けに、次の語彙群で検索流入を獲得したい。

| 語彙 | 例 |
|------|-----|
| 食事会・交流 | 食事会、ランチ会、飲み会 |
| 配膳・発注 | お弁当、デリバリー、仕出し弁当、ケータリング |

**プロダクトの前提**: Shokujii は「配達・仕出し業者」ではなく、**幹事が食事会を企画し、参加者が店舗で食事する**コミュニティイベントプラットフォーム。検索意図が「業者に弁当を注文したい」と「幹事として食事会を開きたい」で分かれるため、**全部を同じ戦略で追わない**。

**SEO 対象**: 主に `user`（shokujii.jp）。`enterprise` Hosting は noindex（[01_SEO対策_タスク.md](./01_SEO対策_タスク.md) 参照）。

**着手タイミング**: Phase 2〜3 本番デプロイ・GSC 再計測（P3-1）・P3-6 判断の**後**（01 の推奨実行順に従う）。

## 2. 検索意図とプロダクト適合度

| キーワード群 | 典型の検索意図 | Shokujii 適合 | 戦略 |
|-------------|---------------|--------------|------|
| **食事会** | 交流会・懇親・チームビルディング | ◎ コア | 最優先。Hub / Locations pSEO |
| **ランチ会** | 社内・異業種の昼食イベント | ◎ コア | 最優先。エリア × ランチ会 |
| **飲み会** | 会食・二次会・懇親 | △ 可能 | サブ。食事会・ランチ会へ誘導する比較・代替記事 |
| **お弁当** | 個別配膳・昼食の一括注文 | △〜× | 教育・比較のみ。量産 pSEO の主軸にしない |
| **デリバリー** | 配達で届ける | × | 全面追わない |
| **仕出し弁当** | 仕出し業者の比較・見積 | × | 全面追わない。比較 1〜3 本まで |
| **ケータリング** | イベント向け業者手配 | △ | 比較・選び方ガイドで間接獲得 |

**結論**

- **本命**: 食事会・ランチ会 ×（幹事 / エリア / シーン）
- **間接**: ケータリング・仕出し弁当・お弁当 → **「ケータリング vs 食事会プラットフォーム」等の Consideration コンテンツ**
- **非推奨**: 「◯◯ 仕出し弁当 おすすめ」「法人 デリバリー 弁当 安い」等の**業者比較・価格比較**の量産 pSEO

## 3. コンテンツピラー（5 本）

/content-strategy の Searchable 優先。各ピラーは Searchable / Shareable / 両方を明記。

### ピラー A：幹事・人事・総務向け「食事会のやり方」（Searchable + Shareable）

| 項目 | 内容 |
|------|------|
| **対象** | 初めて社内ランチ会・食事会を任された幹事・人事 |
| **プロダクト接続** | 幹事ツールとして Shokujii、申込・集金・店舗選び |
| **プレイブック** | Glossary / ガイド、Personas（01 P4-0-4） |
| **URL 案** | `/guides/kanji/` 等（P4-4 で確定。現状は未実装） |

**サブトピック（クラスタ）**

| バイヤー段階 | 例キーワード | コンテンツ型 |
|-------------|-------------|-------------|
| Awareness | 食事会 幹事 やり方、ランチ会 企画、社内 交流 ランチ | ハウツー |
| Consideration | 食事会 サービス 比較、ケータリング 食事会 違い、仕出し弁当 社内交流 | 比較記事 |
| Decision | shokujii 使い方、食事会 申込 一括 | プロダクト連携 LP |

---

### ピラー B：エリア × 食事会 / ランチ会（Searchable・pSEO 本命）

| 項目 | 内容 |
|------|------|
| **対象** | 「東京 ランチ会」「神田 食事会」等の地域検索 |
| **プロダクト接続** | 該当エリアの公開イベント一覧 → `/c/**/e/**` |
| **プレイブック** | Locations、Locations × ジャンル（01） |
| **URL 案** | `/events/tokyo/` → `/events/tokyo/kanda/lunch/`（P4-4） |
| **独自性** | 開催実績数・参加人数・店舗名（Firestore 由来） |

**薄いコンテンツ対策（P4-0-3）**

- 掲載イベント **0 件** → ページ**未生成** or **noindex**
- ページ固有の価値: 件数・直近開催・写真（AlbumItem）

### ピラー D：配膳・発注ワードの間接獲得（Searchable・Consideration のみ）

お弁当・デリバリー・仕出し弁当・ケータリングを**捨てずに**触る場合の方針。

| 方針 | 例コンテンツ |
|------|-------------|
| 意図のすり替え（教育） | 「法人 お弁当 注文」の前に — 参加者が選べる社内食事会 |
| 比較 | ケータリング vs 食事会プラットフォーム、仕出し弁当 vs 店舗で食べるランチ会 |
| ギャップ明示 | デリバリー弁当では代替できない対面交流 |

**禁止に近い施策**

- 「◯◯ 仕出し弁当 おすすめ」「法人 デリバリー 弁当 安い」の量産 pSEO
- 店舗公開ページ（P4-5）完成前の Directory 型「ケータリング 業者 東京」

---

### ピラー E：実績・コミュニティ（Shareable + Searchable 補助）

| 項目 | 内容 |
|------|------|
| **形式** | 開催レポート、コミュニティ紹介、写真付き事例 |
| **データ** | Event 参加人数、Community / AlbumItem（独自性 ◎） |
| **接続** | 既存 `/c/{account}`、`/c/{account}/e/{id}` への内部リンク |

## 4. Hub / Spoke 構造（案）

```
shokujii.jp/
├── （Hub）企業の食事会・ランチ会ガイド          … ピラー A
│   ├── 幹事のやり方
│   ├── ケータリング・仕出しとの違い
│   └── 新入社員 / 異業種 / 少人数 …
├── （Hub）エリア別の食事会・ランチ会            … ピラー B（pSEO）
│   ├── /events/tokyo/
│   ├── /events/osaka/
│   └── … → 個別 /c/.../e/... へリンク
├── /communitylist                               … 既存
└── /c/{account}/e/{eventId}                     … 既存（Phase 2〜3 SEO 強化済み）
```

**カニバリ回避（P4-0-2）**

| URL 種別 | 役割 | 主キーワード |
|---------|------|-------------|
| `/c/**/e/**` | 個別イベント詳細 | イベント名・店名・日時 |
| `/events/{area}/` | エリア集約ハブ | {エリア} 食事会 / ランチ会 |
| `/guides/**` | 幹事・比較ガイド | 幹事 やり方、ケータリング 違い |

## 6. Searchable vs Shareable 分類

| 分類 | ピラー | 例 | 備考 |
|------|--------|-----|------|
| **Searchable** | B, C（一部） | {エリア} ランチ会、新入社員 ランチ会 | pSEO・Locations が中心 |
| **Shareable** | E | 開催レポート、幹事の体験談 | SNS・被リンク想定 |
| **両方** | A, D | 幹事ガイド、ケータリング比較 | 検索もシェアも |

/content-strategy 原則: **Searchable を優先**（検索需要が基盤）。
