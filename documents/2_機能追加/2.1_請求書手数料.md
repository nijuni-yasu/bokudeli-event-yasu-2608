## 請求書手数料機能

### 概要
- イベントでの支払い方法について、主催者請求書払い（community_bill）を行うことができる。
- 請求書のPDFについて、支払い金額を +10% に加算する。
- ※請求書のPDFを発行する機能は実装済。

### セキュリティルールの更新

`firestore.rules`に手数料関連フィールドの権限を追加：

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // ... 既存ルール ...
    
    match /communities/{communityId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && 
        (resource == null || 
         request.auth.uid in resource.data.managers ||
         request.auth.uid in resource.data.members);
      
      // 手数料設定は管理者のみ編集可能
      allow update: if request.auth != null && 
        request.auth.uid in resource.data.managers &&
        request.resource.data.diff(resource.data).affectedKeys()
          .hasOnly(['community_bill_fee_rate', 'community_bill_fee_enabled', 'updated_at']);
    }
  }
}
```

### 画面表示仕様

- イベント作成時、主催者請求書払い（community_bill）を設定する際に手数料率を明記する
- 請求書PDFに手数料明細を表示する

### 拡張性

- 料率はコミュニティごとに設定できるように、communityDocで設定できるようにする
- オプションのデータ。存在しない場合は10%
- 今後無料キャンペーンなどを実行しやすいようなデータ構造
