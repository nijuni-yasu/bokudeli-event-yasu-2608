# 追加機能_フォーム機能_仕様書

※ 仕様概要については、documents/1.仕様概要.md に記載しているので参考にすること。

## 1. 概要

### 1.1 狙い
- 主催者獲得施策として、イベント参加者からの事前情報収集を実現
- 主催者はメールアドレス、名前、企業名などの事前アンケートを回収し、ビジネスイベントとして効果的に実施

### 1.2 機能概要
- 管理者がコミュニティ管理画面でフォームを作成・管理
- イベント作成時に事前作成フォームを連携
- 参加者が注文時にフォーム回答を実施
- 管理者が回答内容を確認・ダウンロード可能

## 3. データ構造

### 3.1 FormDoc（フォーム定義）
```typescript
interface FormDoc {
  form_id: string;                    // フォームID（自動生成）
  community_id: string;               // コミュニティID（既存システムとの連携）
  form_name: string;                  // フォーム名
  form_description?: string;          // フォーム説明
  form_contents: FormField[];         // フォーム項目配列
  settings: FormSettings;             // フォーム設定
  created_at: Timestamp;              // 作成日時
  updated_at: Timestamp;              // 更新日時
  created_by: string;                 // 作成者ID（コミュニティ管理者）
  updated_by: string;                 // 作成者ID（コミュニティ管理者）
  is_deleted: boolean;                // 削除フラグ（既存システムとの統一）
}

interface FormField {
  field_id: string;                   // 項目ID（自動生成）
  field_name: string;                 // 項目名
  field_type: FormFieldType;          // 項目タイプ
  field_description?: string;         // 項目説明
  is_required: boolean;               // 必須フラグ
  validation?: ValidationRule;        // バリデーション設定
  options?: FieldOption[];            // 選択肢（チェックボックス、ラジオ、ドロップダウン用）
  display_order: number;              // 表示順序
  // conditional_logic?: ConditionalLogic; // 条件分岐設定
}
```

## 5. フォーム機能固有の技術実装

### 5.1 フォームバリデーション

- 条件付きバリデーション（他項目の回答に応じた必須チェック）

### 5.2 ファイルアップロード機能

- ファイル形式・サイズ制限の実装
- アップロード進捗表示
- セキュアなファイルアクセス制御

- 依存関係のある項目の連動更新

### 5.4 回答データ管理
