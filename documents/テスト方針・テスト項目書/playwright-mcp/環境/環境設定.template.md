sandbox / development の Hosting URL と Phase A 試行用 fixture を記録する。
**本番（production）URL は使用禁止。**

## 使い方

1. 本ファイルをコピーし、同ディレクトリに `環境設定.local.md` を作成する
2. 各項目を埋める（`環境設定.local.md` は gitignore 対象でコミットしない）
3. [`PhaseA_試行手順.md`](../手順/PhaseA_試行手順.md) に従って試行する

| 変数 | 値（記入） | 用途 |
|:--|:--|:--|
| `TEST_COMMUNITY_ACCOUNT` | | 公開コミュニティの account（URL `/c/{account}`） |

## Fixture の取得方法

1. ブラウザで `USER_BASE_URL` を開く（未ログイン）
2. トップまたはコミュニティ一覧から**公開**イベントを 1 件開く
3. URL から取得:
   - `/c/{TEST_COMMUNITY_ACCOUNT}/e/{TEST_EVENT_ID}` → account と eventId
4. イベント参加者または公開プロフィールリンクから `TEST_USER_UID` を取得
   - トップに `/u/` リンクが無い場合: **コミュニティ詳細**（`/c/{account}`）の Manager / メンバー欄を確認
5. 公開イベントが 1 件もない場合: U-03 / U-04 は **SKIP**（手順書に記録）
