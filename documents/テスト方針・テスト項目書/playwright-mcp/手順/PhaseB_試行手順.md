### 重要: ログインの扱い

Firebase Auth（Google / X / Facebook / メール）は **MCP から OAuth 自動ログインできない**。

1. AI に「ログイン画面を開いて」と依頼する
2. **MCP が起動したブラウザ上**で、人間がテストアカウント（`LOGIN_USER_UID` に紐づくアカウント）でログインする
3. ログイン完了後、AI に「ログイン済み。続きを確認して」と依頼する

**注意**: MCP ブラウザと通常の Chrome は **セッションを共有しない**。必ず MCP 経由で開いたウィンドウでログインすること。

## 6. 既知の制約

| 項目 | 内容 |
|:--|:--|
| OAuth | MCP から自動ログイン不可 → 人手ログイン必須 |
| Stripe | U-06 / 決済完了は Phase B 対象外 |
| partner ドメイン | user は `{USER_BASE_URL}`。partner は `{PARTNER_BASE_URL}`（環境により Hosting 直 URL） |
| 401 / 403 | 一部 API（Channel.io 等）は未ログイン・権限で 401/403 でも UI 表示は問題ない場合あり |
