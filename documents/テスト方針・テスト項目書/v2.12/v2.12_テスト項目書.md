## 2. 重点確認ポイント

v2.12 は **PF データ整合（`0046`）** と **モバイルチャット v2** が最重要。次に Node 24 実走・SEO・partner 権限。

1. **`0046` 未完了のまま user を公開すると、既存注文が PF プロフィールから消える**（[#2198](https://github.com/nijuniinc/bokudeli-event-new/issues/2198)）
2. チャット v2 は **iOS Safari の画像 DL / Web Share** がデスクトップだけでは検出できない
3. Node 24 は **sharp / Adobe PDF / SendGrid v8** が実行時のみエラーになりうる
4. SEO は **`handleSitemapRequest` デプロイ前に user Hosting が走ると 400**（[#2202](https://github.com/nijuniinc/bokudeli-event-new/issues/2202)）
5. エンプラは本番 go-live しないが、**PF（shokujii.jp）が壊れていないこと**を必ず確認
