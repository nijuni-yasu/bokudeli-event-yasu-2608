# イベントコピー機能

## 1. 概要
### 1.1 機能の目的
既存イベントを簡単に複製し、主催者の新規イベント作成の手間を削減する。

### 1.2 主要な機能
- 管理画面のイベント一覧からイベントをコピー
- イベント詳細ページからそのイベントをコピー
- コピー時、「カバー画像」「店舗」「メニュー」など全情報を複製
- メニューは「元イベントのmenus」ではなく「partnerIdが持つmenusコレクション（店舗メニュー）」からコピー
- 開催日時は「同じ時刻・同じ曜日」かつ「現在日時から2週間以上後」に自動調整
- タイトル末尾に「のコピー」を付与
- コピー後は「下書き保存」状態となる

### 1.3 対象ユーザー
- イベント主催者（管理画面利用者）

## 2. ねらい
### 2.1 ビジネス目標
- 主催者のイベント作成工数削減
- イベント開催数の増加

### 2.2 ユーザー価値
- 過去イベントの再利用による効率化
- ミスの少ないイベント作成

### 2.3 成功指標（KPI）
- コピー機能経由で作成されたイベント数
- コピー後のイベント公開率

## 3. 前提条件
### 3.1 技術的前提条件
- Firestoreにイベント・メニュー・店舗情報が正しく保存されていること
- ユーザーがイベント編集権限を持っていること

### 3.2 ビジネス的前提条件
- コピー元イベントが「下書き」以外でもコピー可能

### 3.3 依存関係
- イベント管理画面（user/src/componentsLocal/manage/event/overview.vue）
- イベント一覧画面（user/src/componentsLocal/manage/community/events.vue）
- イベントデータスキーマ（common/src/schemas/Event.ts）
- パートナー店舗メニュー（partnerId/menusコレクション）

## 4. 画面仕様
### 4.1 画面遷移
```
① イベント一覧ページからコピー
  ├─ 「イベント作成」ボタン
  ├─ 「イベントをコピーする」ボタン
       └─ モーダルでイベント一覧を表示 → コピーしたいイベントを選択 → 下書き作成 → イベント一覧画面に遷移

② イベント詳細ページからコピー
  └─ イベント詳細（overview.vue）
       └─「イベントをコピーする」ボタン → 新規イベントが下書き作成 → イベント一覧画面に遷移
```

### 4.2 UI要素
- **「イベントをコピーする」ボタン（イベント一覧ページ）**
  - 「イベント作成」ボタンの右隣に設置
  - クリックでモーダルが開き、過去イベントの一覧が表示される
  - 一覧からコピーしたいイベントを選択可能
- **コピー用モーダル画面**
  - 過去イベントのリスト（タイトル・開催日・ステータス等）
  - 検索・絞り込み機能（任意）
  - 「このイベントをコピー」ボタン
  - キャンセルボタン
- **「イベントをコピーする」ボタン（イベント詳細ページ）**
  - 各イベント詳細画面（overview.vue）に設置
  - クリックでそのイベントを即コピー
- **イベント一覧画面**
  - コピー後の新規イベント（下書き）がリスト最上部に表示される
  - 必要に応じて「下書き」ラベル等で区別

### 5.2 Functions設計
#### 5.2.1 Callable Functions
- `copyEvent`: イベントIDを受け取り、複製イベントを作成
  - **引数**: `eventId: string`
  - **戻り値**: `newEventId: string`
  - **認証**: 主催者のみ
  - **処理内容**:
    - イベント本体情報をコピー
    - メニューは「partners/partnerId/menus」サブコレクションから取得し、events/{newEventId}/menusに複製
    - その他にコピーが必要なサブコレクションはない。

#### 5.2.2 Trigger Functions
- なし

#### 5.2.3 Scheduled Functions
- なし

### 5.3 処理フロー
【① イベント一覧ページからコピー】
1. 主催者がイベント一覧画面で「イベントをコピーする」ボタンをクリック
2. モーダルで過去イベント一覧が表示される
3. コピーしたいイベントを選択し「このイベントをコピー」ボタンを押下
4. フロントエンドで`copyEvent`関数（Cloud Functions）を呼び出し
5. サーバー側でイベント情報を複製
6. メニューは「partners/partnerId/menus」サブコレクションから取得し、events/{newEventId}/menusに複製
7. タイトル末尾に「のコピー」を付与
8. 開催日時を「同じ時刻・同じ曜日」かつ「2週間以上後」に自動調整
9. 新規イベントを「下書き」状態で保存
10. イベント一覧画面（community/events.vue）に遷移し、コピーされたイベントが表示される

【② イベント詳細ページからコピー】
1. 主催者がイベント詳細画面で「イベントをコピーする」ボタンをクリック
2. フロントエンドで`copyEvent`関数（Cloud Functions）を呼び出し
3. サーバー側でイベント情報を複製
4. メニューは「partnerId/menus」コレクションから取得し、events/{newEventId}/menusに複製
5. タイトル末尾に「のコピー」を付与
6. 開催日時を「同じ時刻・同じ曜日」かつ「2週間以上後」に自動調整
7. 新規イベントを「下書き」状態で保存
8. イベント一覧画面（community/events.vue）に遷移し、コピーされたイベントが表示される

## 7. 注意事項
### 7.1 既存システムへの影響
- イベントIDの重複防止
- コピー元イベントの編集・削除には影響しない

### 7.2 セキュリティ考慮事項
- 認証・権限チェック必須
- コピー先イベントの公開前バリデーション
- メニューコピー時も権限・整合性に注意

### 7.3 運用考慮事項
- 店舗が閉店・非承認・営業日外の場合、予約申請時にバリデーション
- NG時は「このお店を選択できません」モーダル表示＋店舗選択画面へ遷移
