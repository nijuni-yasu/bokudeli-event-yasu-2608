# イベントページの仮保存機能

## 1. 概要

### 1.1 機能の目的
イベントページ作成時の4ステップのうち、最初のステップ（基本情報入力）完了時に、イベントの新規作成・仮保存機能を提供し、ユーザーの入力ストレスを軽減する。

### 1.2 主要な機能
- イベント基本情報入力時のイベント新規作成・仮保存。
- イベント基本情報入力画面で「保存して進む」を押下したときに自動で仮保存する。

### 1.3 対象ユーザー
- イベント主催者
- コミュニティ管理者

## 2. ねらい

### 2.1 ビジネス目標
- イベント作成の離脱率を30%削減
- 主催者獲得率の向上

### 2.2 ユーザー価値
- イベント作成プロセスのストレス軽減
- 途中保存による安心感の提供

### 2.3 成功指標（KPI）
- イベント作成完了率の向上
- 仮保存から本保存への変換率
- ユーザー満足度スコア

## 3. 前提条件

### 3.1 技術的前提条件
- Firestoreデータベース
- Vue.js 3 + TypeScript
- Firebase Authentication
- 既存のイベント作成フロー（4ステップ）

### 3.2 ビジネス的前提条件
- コミュニティが存在すること
- ユーザーが主催者権限を持っていること
- イベント作成の4ステップフローが確立されていること

### 3.3 依存関係
- コミュニティ管理機能
- イベント作成コンポーネント群
- ユーザー認証システム

## 4. 画面仕様

### 4.1 画面遷移
```
イベント作成開始
    ↓
基本情報入力画面（base/src/components/eventcreate/EventBasicInfoCard.vue）
    ↓
[仮保存実行] （※基本情報入力画面で「保存して進む」を押下するタイミング）
    ↓
飲食店選択画面（base/src/components/eventcreate/EventShop.vue）
    ↓
イベント詳細入力画面（base/src/components/eventcreate/EventDetailCard.vue）
    ↓
飲食店情報入力画面（base/src/components/eventcreate/EventShopNotice.vue）
    ↓
[下書き保存] or [予約申請実行] 
```

### 4.2 UI要素
- 新規で仮保存する時は「次へ」ボタンを「保存して進む」ボタンに文言修正
- すでに存在するイベントの場合は「次へ」と表示する
- 仮保存 完了通知トースト
- 仮保存 エラー通知トースト

## 5. 技術仕様・データ構造設計

### 5.1 Firestoreスキーマ
```typescript
// イベントドキュメント
interface EventDraft {
  // 基本情報（必須）
  event_status: 'in_draft'

  // 基本情報（仮保存時に入力）
  event_start_datetime: Timestamp;
  event_end_datetime: Timestamp;
  event_postcode: string;
  event_address: string;
  
  // 仮保存時のデフォルト値
  event_title: string; // "[コミュニティ名]のイベント"
  event_cover_image: string; // コミュニティカバー画像
  event_description: string; // "[コミュニティ名]のイベント"
  payment_method: 'user_advance'; // デフォルト値
  max_participants: number; // デフォルト値: 25
  
  // 後から入力される項目（オプション）
  shop_id?: string;
  shop_name?:string;
  event_deadline_datetime?: Timestamp;
  
  // 主催者情報（予約申請時に必須）
  organizer_name?: string;
  organizer_email?: string;
  organizer_phone?: string;
}
```

### 5.2 Firestoreフロントエンド処理
- **データ更新処理**: 基本情報入力時に仮保存実行
- **リアルタイム監視**: イベントステータスの変更を監視
- **エラーハンドリング**: 保存失敗時のリトライ機能


### 5.4 Functions設計
なし

### 5.5 処理フロー

#### 5.5.1 仮保存処理フロー
1. ユーザーが基本情報（日時・場所）を入力
2. フォームバリデーション実行
3. 仮保存用データを構築（デフォルト値設定）
4. Firestoreにイベントドキュメント作成
5. 成功通知を表示
6. 次のステップ（飲食店選択）に遷移
