## トラブルシュート（v2.10 実績）

### `flyer` / `slackbot` の UpdateFunction 404

**症状**（Cloud Audit / Actions ログ）:

```text
UpdateFunction ... functions/flyer — Resource was not found
UpdateFunction ... functions/slackbot — Resource was not found
```

**原因**: Gen1 削除対象と混同して **`flyer` / `slackbot` を手動削除**したあと、CLI が **create ではなく update** としてデプロイした。

**対処**（他関数はデプロイ済みのため、欠けている 2 件だけ再デプロイ）:

```bash
firebase --project bokudeli-event-dev deploy --force \
  --only functions:flyer,functions:slackbot
```

ログに `creating` と出れば OK。まだ `updating` → 404 のときは、上記を再実行するか Actions の **Deploy functions** を `workflow_dispatch` で再実行する。

**影響**: `flyer` 未復旧 → PDF チラシ不可。`slackbot` 未復旧 → Slack OAuth / スラッシュコマンド不可（`slackEventNotification` 等の通知関数とは別）。

### Cloud Scheduler `eventNotification` の NOT_FOUND

**症状**:

```text
AttemptFinished ... firebase-schedule-eventNotification-asia-northeast1
status: NOT_FOUND
```

**原因**: 関数を `slackEventNotification` に移行したあと、**旧 Scheduler ジョブだけ孤立**。

**対処**: [C-1 の Scheduler 表](#c-1-gen2-旧-slack-通知名の削除二重通知防止) に従い、旧 `firebase-schedule-eventNotification-*` のみ削除。新 `firebase-schedule-slackEventNotification-*` は残す。

### CLI の注意

| コマンド | 注意 |
| -------- | ---- |
| `firebase functions:list` | **`--region` オプションは使えない**（unknown option エラー） |
| `gcloud scheduler jobs list` | `--project=... --location=asia-northeast1`（ハイフン区切り。`--project=...--location=` は誤り） |
