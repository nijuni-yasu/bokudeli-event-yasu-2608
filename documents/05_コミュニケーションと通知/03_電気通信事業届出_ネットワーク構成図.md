## 3. 通信経路の説明

### 3.1 全体構成

1. 利用者 A・B がそれぞれの端末（Webブラウザまたはスマートフォン）から Shokujii アプリにアクセスする。
2. 端末からの通信は、各利用者が契約する既存のインターネット接続サービス事業者（ISP）のネットワークを経由してインターネットに接続される。
3. インターネット経由で、Firebase / Google Cloud 上の各サービスと HTTPS 等で通信する。
4. 利用者同士のメッセージは、Firebase / Google Cloud 上のアプリ・データベース・Functions を介して媒介される。

### 3.2 Firebase / Google Cloud の役割

| サービス | 役割 |
| --- | --- |
| Firebase Hosting | Shokujii Webアプリ（フロントエンド）の配信 |
| Firebase Authentication | ログイン済み利用者の認証 |
| Cloud Firestore | チャットルーム、メッセージ、参加情報の保存 |
| Cloud Functions for Firebase | ルーム参加同期、メッセージ作成後処理、送信取り消し、読み取り専用化 等 |

### 3.3 回線非設置の整理

ニジュウニ株式会社は、自社で電気通信回線設備を設置しない。サーバー基盤は Firebase / Google Cloud のクラウドサービスを利用し、利用者端末からインターネットへの接続は各利用者の ISP 経由とする。

## 4. 提供しない機能

構成図の補足事項として、以下を明示する。

- IP電話
- 音声通話
- ビデオ通話

提供するのは、特定の利用者間に限定したテキストメッセージのクローズドチャットのみである。

## 5. 閲覧・PDF 化

- **ブラウザ**: `03_電気通信事業届出_ネットワーク構成図.svg` を Chrome / Safari / Firefox にドラッグ＆ドロップする。
- **Cursor / VS Code**: ファイルを開き、SVG プレビュー拡張があればプレビュー表示する。
- **PDF 化**: ブラウザで開き、「印刷」→「PDF として保存」。e-Gov で SVG が使えない場合は PDF を添付する。

## 6. e-Gov 提出時の注意

- 添付ファイル形式は SVG を使用する。e-Gov の様式第3 添付欄に本 SVG をアップロードする。
- 印刷提出が必要な場合は、A4 縦向きで読み取り可能な解像度であることを確認する。
- 図面に届出者名・提供役務名が記載されていることを提出前に確認する。
- 技術構成の大幅な変更（自社回線設備の設置、主要クラウド基盤の変更等）があった場合は、変更届出の要否を管轄総合通信局等へ確認する。

## 7. 管轄への確認事項（参考）

事前相談時に、以下を確認しておくとよい。

- Firebase / Google Cloud の概略構成を示す本図で足りるか
- 回線非設置の届出として、ISP ネットワークを「既存のインターネット接続サービス事業者のネットワーク」と記載する表現で問題ないか
- Cloud Firestore 等の具体的サービス名を図中に記載してよいか
