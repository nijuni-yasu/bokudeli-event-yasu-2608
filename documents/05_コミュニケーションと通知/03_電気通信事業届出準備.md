# 電気通信事業届出準備

## 1. 概要

### 1.1 目的

Shokujii のチャット機能を提供するにあたり、総務省（管轄の総合通信局等）への電気通信事業届出に必要な判断材料・記載案・確認事項を整理する。

本ドキュメントは届出書類を作成するための作業メモであり、最終判断は管轄の総合通信局等、または弁護士・行政書士等の専門家に確認する。

### 1.2 対象機能

対象は `01_チャット機能.md` で定義するアプリ内チャット機能。

- 個人チャット（1:1）
- グループチャット（イベント参加者限定）
- グループチャット（コミュニティメンバー限定）
- システムメッセージ
- アプリ内未読管理
- 送信取り消し
- 将来フェーズのプッシュ通知連携

### 1.3 結論

現時点では、Shokujii のチャット機能は **届出電気通信事業として届出が必要となる可能性が高い**。

理由は、イベント参加者・コミュニティメンバー・たべとも等、特定の利用者間に閉じたテキストメッセージの送受信をアプリが媒介するため。総務省の電気通信事業参入マニュアルでは、オープンチャットや電子掲示板は「他人の通信を媒介していない」と整理される場合がある一方、クローズドチャット/オンライン会議は「特定の利用者の間のみに閉じた会話等を媒介するもの」として登録又は届出が必要な電気通信事業とされている。

Shokujii は自社で電気通信回線設備を設置する ISP 的な役務ではなく、Firebase / Google Cloud 上でアプリ内メッセージを媒介する構成であるため、現時点の整理では **登録ではなく届出** を前提に準備する。

## 3. 届出要否の整理

### 3.1 判断軸

| 判断軸 | Shokujii の整理 |
| --- | --- |
| 他人の通信を媒介するか | ユーザー同士のメッセージを Firestore / Functions を通じて送受信させるため、媒介に該当する可能性が高い |
| 不特定多数向けの公開掲示板か | 参加条件のある閉じたルームであり、公開掲示板ではない |
| 特定利用者間の閉じた通信か | event / community / direct の各 room は参加者が限定される |
| 電気通信回線設備を自ら設置するか | 現時点では自己設置なし。Firebase / Google Cloud を利用 |
| 届出か登録か | 自己設置の回線設備を前提としないため、届出を前提に整理 |

### 3.2 機能別の該当性

| 機能 | 届出論点 | 整理 |
| --- | --- | --- |
| 個人チャット（1:1） | たべとも同士の閉じたメッセージ | クローズドチャット性が強い |
| イベントグループチャット | イベント参加者に限定した会話 | 特定利用者間の閉じた会話 |
| コミュニティグループチャット | コミュニティメンバーに限定した会話 | 特定利用者間の閉じた会話 |
| システムメッセージ | Functions が生成する参加通知 | ユーザー間通信ではないが、チャット役務の一部 |
| 未読管理 | メッセージ到達・閲覧状態の管理 | チャット役務の付随機能 |
| プッシュ通知 | 新着メッセージ通知 | チャット役務の付随機能。通知本文を含める場合は通信の秘密・個人情報の観点で別途確認 |

### 3.3 オープンチャットではない理由

Shokujii のチャットは、ログイン済みであることに加え、以下の参加条件を満たすユーザーのみが対象となる。

- `event.members` に含まれるイベント参加者
- `communities/{communityId}/members/{userId}` が存在するコミュニティメンバー
- `users/{uid}/friends/{friendUserId}` が存在するたべとも

不特定多数が閲覧・投稿できる公開掲示板ではなく、Firestore Security Rules と membership により閲覧・投稿可能者を限定する設計である。

### 5.2 様式第4: 提供する電気通信役務に関する書類

様式第4 は、提供する電気通信役務の種類と具体的なサービス内容を記載する書類である。e-Gov 入力時は、公式様式の「電気通信役務の種類」欄で該当区分に **○** を付し、「提供する役務」欄に具体的なサービス名を記載する。

#### 5.2.1 e-Gov 入力手順

1. **電気通信役務の種類** 欄で、該当する区分の **○** のみを選択する。
2. Shokujii のチャット機能では、**31 インターネット関連サービス（IP電話を除く。）** の **○** を選択する。
3. **提供する役務** 欄に、区分 31 に対応する具体的なサービス名を記載する。公式様式の注記どおり、区分 31 を選択した場合は「クローズドチャット」等の具体的な役務名を併記する。
4. 区分 1〜30、32〜35 は、Shokujii の現行チャット機能には該当しないため **選択しない**。将来、音声通話・ビデオ通話・IP電話等を追加する場合は、該当区分の選択要否を改めて確認する。

#### 5.2.2 公式様式の注記（区分 31）

公式様式には、区分 31 を選択する場合の注記がある。

> 31 を選択した場合は、提供する役務の欄に、インターネット関連サービス（IP電話を除く。）のうち、提供する具体的なサービス（例：クローズドチャット）を記載すること。

この注記に従い、区分 31 の選択だけでは不十分であり、**提供する役務** 欄への具体記載が必須である。

| 項目 | 記載案 |
| --- | --- |
| 電気通信役務の種類 | **31** インターネット関連サービス（IP電話を除く。）の **○** を選択 |

| 音声・ビデオ通話の有無 | なし |
| ファイル送信の有無 | 現時点ではなし。将来追加する場合は変更届出要否を確認 |

```text

```

## 6. Shokujii 側の技術仕様メモ

### 6.1 データ保存場所

チャット関連データは主に以下に保存する。

```text
/chat_rooms/{roomId}
  /messages/{messageId}

/users/{userId}/chat_memberships/{roomId}
```

関連データ:

```text
/communities/{communityId}
  /events/{eventId}
    /members/{userId}
    /orders/{orderId}
  /members/{userId}

/users/{userId}
  /friends/{friendUserId}
```

### 6.2 メッセージ本文

- ユーザー投稿の本文は `chat_rooms/{roomId}/messages/{messageId}.body` に保存する。
- 送信取り消し時は本文を Firestore から削除し、`deleted_at` 等のトゥームストーン情報のみ残す。
- システムメッセージは `message_type: 'system'` として保存し、本文ではなく `system_event` / `system_params` から表示する。

### 6.3 閲覧・投稿権限

- ルーム参加者のみがメッセージを読める。
- 離脱したユーザーの `chat_memberships/{roomId}` は削除し、Security Rules により以後の閲覧・投稿を不可にする。
- 読み取り専用化されたルームは履歴閲覧のみ可能とし、新規投稿は不可にする。

### 6.4 運用者による閲覧

通信の秘密の保護を前提に、運用者がメッセージ本文を閲覧できるケースは最小限に限定する必要がある。

検討すべき運用:

- 通報対応
- 法令に基づく照会対応
- 不正利用・安全確保のための調査
- 障害調査時の本文閲覧禁止又はマスキング
- Firebase Console / Admin SDK へのアクセス権限管理
- アクセスログ・操作ログの保存

## 7. 届出後に必要な運用

### 7.1 通信の秘密

電気通信事業者として、通信の秘密の保護が重要な義務となる。チャット本文、送受信者、送受信時刻、参加ルーム等は通信の秘密又はそれに近い情報として慎重に扱う。

必要な対応:

- メッセージ本文を通常運用で閲覧しない。
- **添付画像**も、メッセージ本文と同様に通常運用で閲覧しない。
- 管理画面等に本文検索・閲覧機能を安易に追加しない。
- 通報対応等で閲覧する場合の権限・手順・記録を定める。
- 送信取り消し時は、Firestore 上の本文・添付メタデータおよび Cloud Storage 上の画像ファイルを削除する。
- Firebase / Google Cloud の IAM 権限を最小化する。
- 本番データを開発環境へコピーしない。

### 7.2 個人情報・外部送信規律

チャット機能そのものに加え、以下の文書更新が必要になる可能性がある。

- 利用規約
- プライバシーポリシー
- Cookie / 外部送信ポリシー
- 通報・ブロック・削除依頼に関するヘルプ

**2026-06-26 更新**: `documents/11_法務文書/ユーザー利用規約.md` および `documents/11_法務文書/プライバシーポリシー.md` に、イベント参加者向けチャット、画像添付、送信取り消し、Cloud Storage 委託、通信内容の取扱いを追記済み。Notion 公開および法務レビューは未完了。

特に、プッシュ通知でメッセージ本文や送信者名を外部サービスへ送る場合は、通知基盤・外部送信先・表示内容を別途確認する。

### 7.3 変更届出の要否確認

以下の変更時は、変更届出又は電気通信役務の変更報告が必要になる可能性があるため、事前に管轄へ確認する。

- 音声通話・ビデオ通話の追加
- ファイル送信の追加
- 不特定多数向け公開チャットへの変更
- 海外向け提供の開始
- 事業主体・本店所在地・代表者等の変更
- Firebase / Google Cloud 以外への主要構成変更
- 自社で電気通信回線設備を設置する構成への変更
- チャット機能の休止・廃止
