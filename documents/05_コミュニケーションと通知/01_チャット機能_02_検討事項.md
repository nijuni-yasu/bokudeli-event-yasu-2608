## 1. データモデル設計

- [x] **1.1 `chat_rooms.title` と direct ルームの非対称性**
  - 確定: `chat_rooms.title` は event/community のみ（参考用）。direct は未設定。**`chat_memberships` に `title` フィールドは持たない**。一覧表示名は join（`displayTitle`）
  - 反映: §5.1.2 / §5.1.4 / §5.1.6 / §5.2.1

- [x] **1.2 `roomId` 生成ルールの区切り文字衝突**
  - 確定: `event_{community_id}_{event_id}`。Firestore 自動 ID（`community_account` ではない）。`_` 区切り維持
  - 反映: §5.1.2「roomId 生成ルール」

- [x] **1.3 `chat_memberships.unread_count` の上限・下限**
  - 確定: Functions で increment 後 max 99 clamp。表示は 99+ 打ち切り（フロント）。Rules で update は 0 のみ
  - 反映: §5.4 / §5.6

- [x] **1.4 メッセージ本文 2000 文字制限の単位**
  - 確定: Zod 2000 文字、Rules `body.size()` 8000 バイト
  - 反映: §4.2.3 / §5.4

- [x] **1.5 `last_message_preview` の truncate ルール**
  - 確定: Functions で `Array.from(str).slice(0, 100).join('')`
  - 反映: §5.6

- [x] **1.6 メッセージ `created_at` のタイムスタンプ生成**
  - 確定: `FieldValue.serverTimestamp()` + Rules `created_at == request.time`
  - 反映: §5.3 / §5.4
