## 4. 任意 E2E（v1 に画像添付を含める場合）

本体仕様 §6.1 で v1 スコープに含めると判断した場合、**§2 GATE-06** に従い以下を必須化する。詳細は [`01_チャット機能_03_画像添付.md`](./01_チャット機能_03_画像添付.md)。

**前提**: 対象環境の Storage バケットに CORS が設定されていること（`getBlob` / `uploadBytes` 用）。[`terraform/README.md`](../../terraform/README.md) の Storage CORS を apply する（import 前の一時適用手順も同 README に記載）。

**sandbox2604 確認メモ**（2026-06-25）: Firestore Rules 添字参照修正デプロイ後、ローカル DEV（`-m sandbox2604`）で IMG-01（1 枚）・IMG-06（3 枚）を Pass 確認。

| ID | 手順 | 期待結果 | Pass |
| --- | --- | --- | --- |
| IMG-01 | PNG / JPEG 画像を 1 枚選択して送信 | サムネ表示。相手側にも表示 | [x] |
| IMG-02 | サムネをタップ | 拡大表示 | [ ] |
| IMG-03 | 10MB 超の画像 | エラートースト。送信されない | [ ] |
| IMG-04 | 非対応 MIME（例: PDF） | 選択不可またはエラー | [ ] |
| IMG-05 | 画像 + テキスト同時送信 | 両方表示（本文上・画像下） | [ ] |
| IMG-06 | 複数枚（2〜12 枚）を選択して送信 | compose 横スクロールプレビュー・モバイル 2 列 / PC 3 列グリッド。13 枚目はトーストで拒否 | [x] |
| IMG-07 | 複数枚アップロード途中で 1 枚失敗（ネットワーク遮断等） | 既アップロード分が Storage から削除され、Firestore にメッセージが作成されない | [ ] |
