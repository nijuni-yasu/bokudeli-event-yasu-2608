# 競合調査 概要

福利厚生・社内ランチ・食事補助の文脈で、shokujii エンタープライズ版の競合を整理する。

**料金の横並び比較**は [`02_料金比較.md`](./02_料金比較.md) を正本とする。

---

## 1. 調査の目的

| 目的 | 内容 |
|:--|:--|
| 市場把握 | 2026年4月の食事補助非課税上限引き上げ（3,500円→7,500円/月）を踏まえた競合動向 |
| ポジショニング | shokujii が「日常の食事補助」ではなく「食事を通じた社内交流」に立つ位置の明確化 |
| 営業・提案 | 人事・総務向けに、**月額総額**と**1人あたり**の両方で説明できる比較資料 |

---

## 2. shokujii エンタープライズの位置づけ（自社）

| 項目 | 内容 | 正本 |
|:--|:--|:--|
| 主目的 | 福利厚生としての食事補助 **＋** 社内コミュニケーション活性化 | `08_エンタープライズ/01_仕様概要` |
| 利用単位 | **コミュニティ / イベント**（幹事が食事会を立て、参加者が個別注文） | 同上 |
| プラットフォーム利用料 | **MVP デフォルト 500円 / 有効アカウント / 月**（早期導入）。**営業標準は年間 800円**（税込）。お試し3ヶ月無料 | `08_エンタープライズ/02_課金設計` |
| 食事関連従量 | 企業補助分・ゲスト分など **実費の取次（マージンなし）** | `04_請求` |
| 非課税設計 | 従業員50%以上負担、企業負担月7,500円（税別）以下を想定 | `01_仕様概要` |

**競合との本質的な違い**

- チケット型・カード型: **個人の日常ランチ**を補助。交流は副次効果。
- 設置型・デリバリー型: **出社者の昼食環境**を改善。幹事・イベント管理は弱い。
- shokujii: **食事会の企画〜注文〜決済〜集計**を一体化し、偶発的コミュニケーションを主目的とする。

---

## 3. 市場背景（2026年改正）

2026年4月1日以降に支給する食事から、食事補助の非課税上限が **月7,500円（税別）** に引き上げられた。

非課税で運用する主な条件（従来どおり）:

1. 従業員が食事代の **50%以上** を自己負担する
2. 企業負担が **月7,500円（税別）以下**
3. **現物支給**（給与の現金支給ではない）

この改正を契機に、チケットレストラン・miive・HQ・ベネワン・リロクラブ等がサービス拡充・キャンペーンを実施している。

## 4. 競合カテゴリ（6分類）

[食の福利厚生カオスマップ 2026（ワオ株式会社）](https://prtimes.jp/main/html/rd/p/000000064.000047124.html) の分類をベースに整理する。

| # | カテゴリ | 概要 | shokujii との距離 |
|:--|:--|:--|:--|
| 1 | **食事チケット / カード型** | ICカード・Visaカードで全国店舗利用 | 間接競合（予算・制度の奪い合い） |
| 2 | **外食型（近隣店舗アプリ）** | オフィス周辺店を「社食化」 | 間接〜準直接 |
| 3 | **設置型** | 冷蔵庫・自販機をオフィスに設置 | 間接競合 |
| 4 | **デリバリー / 提供型** | 弁当配送・対面販売・ビュッフェ | 一部直接競合 |
| 5 | **福利厚生代行 / プラットフォーム** | 総合福利厚生の枠で食事補助を提案 | チャネル競合 |
| 6 | **交流・情報共有型** | 食事会・グルメ情報（注文・補助なし） | 直接競合 |

## 6. 競合距離マップ

```
直接競合（交流×食事）
├── みんなの社食 … ビュッフェデリバリー、コミュニケーション訴求
├── メシイコ! … 交流目的だが注文・補助・イベント管理なし
└── 社食DELI … 対面販売＋交流。幹事主導のイベントモデルではない

準直接競合（補助＋外食）
├── どこでも社食 / GoSmart … 日常ランチ補助。交流機能は薄い
└── シャショクラブ … 個人弁当中心

間接競合（同じ福利厚生予算）
├── チケットレストラン … 「食事補助ならこれで足りる」最大の代替案
├── miive / 食事補助HQ … 2026年改正後の新世代カード型
└── OFFICE DE YASAI 等 … 出社者向けの別解

チャネル競合
└── リロクラブ / ベネワン / イーウェル … 総合福利厚生の提案枠
```

## 7. 差別化メッセージ（営業向けたたき台）

| 比較対象 | shokujii の切り口 |
|:--|:--|
| チケットレストラン等 | 個人のランチは安くなるが、**部署を越えた会話は設計上増えない** |
| 設置 / デリバリー型 | 出社者向け。**テレワーク・ゲスト・部署限定ランチ会** に弱い |
| みんなの社食 | 交流訴求は同じ。**幹事負担・個別メニュー・補助ルール・全社ダッシュボード** を一体化 |
| 福利厚生代行 | **併用可能**（日常補助＋交流イベントの二層構成） |
