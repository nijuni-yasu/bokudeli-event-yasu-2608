# 料金比較

福利厚生・社内ランチ・食事補助サービスの **月額コスト** を、**会社全体（月額総額）** と **1人あたり** の両方で比較する。

---

## 1. 読み方

### 1.1 コストの3層

競合サービスの料金は、次の3つに分けて理解する。

| 層 | 名称 | 内容 | 例 |
|:--|:--|:--|:--|
| **A** | **システム / プラットフォーム利用料** | SaaS・手数料・月額固定費。利用の有無に関わらず発生しうる | shokujii 年間800円/人/月（定価1,200円） |
| **B** | **食事補助（実費）** | 従業員の食事代のうち企業が負担する部分。非課税枠内 | 最大7,500円/人/月（税別） |
| **C** | **初期費用** | 導入時のみ（入会金・設置費・カード発行料等） | ベネワン入会金 10万円〜 |

本ドキュメントの **シナリオ表** では、原則 **A + B** の月額を示す。**C** は別表。

### 1.2 試算の共通前提

| 項目 | 前提 |
|:--|:--|
| 対象企業規模 | **50 / 100 / 200 / 300 / 500** 名（有効アカウント＝課金対象人数） |
| 食事補助の企業負担上限 | **7,500円/人/月（税別）** — 2026年4月以降の非課税上限 |
| 食事補助の利用率 | シナリオごとに **100% / 50% / 0%** を設定（下表参照） |
| 税表示 | **システム利用料**: 各社表記に準拠。**食事補助**: 税別（7,500円は税別上限） |
| shokujii | `02_エンタープライズ_課金設計` / `03_課金設計案` に準拠。**比較表の shokujii ① は年間契約 800円/人/月**（定価1,200円・33%OFF）。お試し3ヶ月・早期500円は試算対象外 |

### 1.3 利用率シナリオの意味

| シナリオ | 食事補助（B） | 想定 |
|:--|:--|:--|
| **S1: フル活用** | 全員が上限まで企業負担分を利用 | チケット型で全員フルチャージ |
| **S2: 半分活用** | 全員の50%が上限まで利用 | 交流イベント＋一部のみ日常利用 |
| **S3: システムのみ** | 食事補助 0円 | プラットフォームだけ契約、食事は都度 |

## 4. サービス別 料金構造の詳細

### 4.1 shokujii エンタープライズ

```
月額（企業） = 有効アカウント数 × unit_price（税込）  … ①プラットフォーム利用料
            + 食事補助・ゲスト分の実費              … ②従量（マージンなし）
```

**契約期間別 unit_price（定価1,200円・人数ボリューム割引なし）**

| 契約期間 | unit_price | 定価比 |
|:--|--:|:--|
| 年間（標準） | **800円** | 33%OFF |
| 6ヶ月 | **1,000円** | 17%OFF |
| 3ヶ月 | **1,200円** | 定価 |
| 月次 | **1,200円** | 定価 |
| 早期導入（初回契約期間） | **500円** | キャンペーン |
| MVP デフォルト | **500円** | `createEnterprise` 初期値 |

**比較表・S1/S2/S3 の shokujii ① は年間800円で試算。**

| 人数 | ①のみ S3（800円） | ①+②フル S1（800+7,500） | 1人あたり S1 |
|:--|--:|--:|--:|
| 50 | 40,000円 | 415,000円 | 8,300円 |
| 100 | 80,000円 | 830,000円 | 8,300円 |
| 200 | 160,000円 | 1,660,000円 | 8,300円 |
| 300 | 240,000円 | 2,490,000円 | 8,300円 |
| 500 | 400,000円 | 4,150,000円 | 8,300円 |

- お試し: 作成月含む **3暦月** は ① = 0円
- 停止中アカウント（`is_active == false`）は ① の課金対象外
- ② は利用実績に応じて変動（全員フル利用を前提にしない試算も可能）
- ② にマージンは載せない。当該注文の shokujii 収益は **③ 飲食店送客手数料**

### 4.2 チケットレストラン

| 費目 | 目安 | 備考 |
|:--|:--|:--|
| 初期費用 | 0円（キャンペーン） | カード発行料別途の事例あり |

## 7. shokujii の提案パターン（交流中心）

全員が月7,500円の食事補助を使う設計は、**チケット型と同額帯**になりやすい。shokujii の強みは **B の使い方**（イベント単位・部署交流・ゲスト招待）にある。

### 7.1 想定ユースケース（100名企業）

| 用途 | 頻度 | 1回あたり企業負担/人 | 月間 B 概算/人 |
|:--|:--|--:|--:|
| 全社オープンランチ | 週5回 × 20%参加 | 500円 | 2,000円 |
| 部署定例ランチ | 週1 × 30%参加 | 750円 | 900円 |
| 部活・サークル | 月2回 × 10%参加 | 1,000円 | 200円 |
| **合計（参考）** | | | **約 3,100円/人** |

この場合の月額（100名）:

| 費目 | 計算 | 金額 |
|:--|:--|--:|
| ① プラットフォーム | 100 × 800円 | 80,000円 |
| ② 食事実費 | 100 × 3,100円 | 310,000円 |
| **合計** | | **390,000円** |
| **1人あたり** | | **3,900円** |

→ S2（4,550円/人）より低く、**チケット型フル活用（8,300円/人）の約半分** の試算例。

| 3 | 食事補助（B）は **利用率100%が前提のサービス**（チケット型）と **実利用ベース**（shokujii イベント型）で TCO の考え方が異なる |
| 4 | 福利厚生代行（リロクラブ・ベネワン）は **食事以外のメニュー** を含む。食事補助のみで比較すると過大評価になる |
| 5 | 設置型は **テレワーク・外勤者** に公平でない。拠点追加で総額が増える |
| 6 | 2026年キャンペーン（チケットレストラン手数料50%OFF等）は **期間限定**。試算に含めない |
