# 予約申請時のTwilio電話通知

## 1. 概要
### 1.1 機能の目的
イベントステータスが`applying_reservation`から`accepting_order`に変更された際に、お店に対してTwilio自動電話で通知を行い、予約承認プロセスを迅速化する。

### 1.2 主要な機能
- イベントステータス変更時の自動電話通知
- 音声ガイドによる承認・拒否・保留の選択
- 深夜時間帯（0:00-6:00）の電話通知制御
- 承認・拒否の自動処理

### 1.3 対象ユーザー
- 飲食店の管理者・スタッフ

## 2. ねらい
### 2.1 ビジネス目標
- 予約承認までの時間短縮（従来のメールのみから電話通知追加により50%短縮を目指す）
- 予約承認率の向上（電話通知により10%向上を目指す）
- ユーザー体験の向上（迅速な承認による主催者の満足度向上）

### 2.2 ユーザー価値
- 店舗側：リアルタイムでの予約申請通知
- 主催者側：迅速な予約承認による安心感

### 2.3 成功指標（KPI）
- 予約承認までの平均時間
- 電話通知の応答率
- 予約承認率の変化

## 5. 技術仕様・データ構造設計
### 5.1 Firestoreスキーマ
```typescript

// 電話通知ログ
interface PhoneNotificationLog {
  id: string;
  eventId: string;              // イベントID
  partnerId: string;              // 店舗ID
  phoneNumber: string;          // 通知先電話番号
  callSid: string;              // Twilio Call SID
  status: 'pending' | 'completed' | 'failed';
  response?: '1' | '2' | '3' | 'no_response'; // 応答内容
  createdAt: Timestamp;
  completedAt?: Timestamp;
  errorMessage?: string;        // エラーメッセージ
}
```

### 5.2 Functions設計
#### 5.2.1 Trigger Functions（自動実行）
- `onEventStatusChanged`: イベントステータス変更時の電話通知
  - **トリガー**: `events`コレクションのドキュメントの`event_status`フィールドが`in_draft`から`applying_reservation`に変更される
  - **処理内容**: 深夜時間帯チェック → Twilio電話通知実行
  - **権限**: 認証済みユーザー

- `onTwilioWebhook`: TwilioからのWebhook処理
  - **トリガー**: TwilioからのHTTPリクエスト
  - **処理内容**: DTMF応答の処理とイベントステータス更新
  - **権限**: Twilioからの認証済みリクエスト

### 5.3 処理フロー
1. イベントの`event_status`が`in_draft`から`applying_reservation`に変更される
2. 深夜時間帯（0:00-6:00）かチェック（深夜時間帯の場合は電話通知をスキップ）
3. Twilioで電話通知を実行
4. 音声ガイドを再生
5. ユーザーの応答を待機
6. 応答に応じて処理を実行：
   - 1: 承認処理（`event_status`を`accepting_order`に変更）
   - 2: 拒否処理（`event_status`を`in_draft`に変更）
   - 3: 何もしない
   - 無応答: 何もしない
7. ログを記録

### 7.4 コスト考慮事項
- **Twilioコスト例（概算）**:
  - 着信1件（国内）: 約2〜5円/分（音声30秒〜1分程度）
  - 月100件: 数百円〜1000円台程度

### 7.5 音声ガイド仕様
**自動音声の例**:
「こんにちは、shokujiiからの予約申請のお知らせです。〇月〇日 X時X分 開催のイベントに予約申請があります。承認する場合は1を、キャンセルする場合は2を、確認・検討される場合は3を押してください。」


### 7.6 再通知について
- メールでの再通知は行われる
- 電話での再通知は行わない
- 深夜時間帯（0:00〜6:00）は電話通知しない（レアケースと思われるので、翌朝などの再通知は行わない）
