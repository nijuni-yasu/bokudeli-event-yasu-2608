# bokudeli-event-new 仕様概要

## 1. プロジェクト概要

bokudeli-event-newは、コミュニティベースのイベント管理・注文システムです。主に飲食イベントの企画、参加者募集、注文管理を行うWebアプリケーションです。

### 1.1 アーキテクチャ
- **フロントエンド**: Vue 3 + TypeScript + Vuetify
- **バックエンド**: Firebase (Firestore, Functions, Storage, Auth)
- **決済**: Stripe
- **デプロイ**: Firebase Hosting
- **モノレポ構成**: 複数のアプリケーション（user, admin, curry, manager）を共有コードベースで管理

## 2. 主要エンティティ

### 2.1 コミュニティ (BokudeliCommunity)
- イベントを主催するグループ単位
- 主な属性：
  - `community_id`: コミュニティID
  - `community_name`: コミュニティ名
  - `community_account`: コミュニティアカウント（URL用）
  - `community_cover_image_url`: カバー画像
  - `community_icon_image_url`: アイコン画像
  - `community_desc`: 説明
  - `community_manager_fullname`: 管理者名
  - `community_company`: 会社名
  - `community_email`: メールアドレス
  - `community_phone`: 電話番号
  - `community_postalcode`: 郵便番号
  - `community_address`: 住所
  - `community_sns_*`: SNS情報
  - `community_use_purpose`: 利用する理由
  - `community_num_members`: コミュニティメンバー数
  - `is_public`: 公開フラグ
  - `is_approved`: 運営承認フラグ
  - `members`: メンバーリスト
  - `managers`: 管理者リスト

### 2.2 イベント (BokudeliEvent)
- コミュニティが主催する個別のイベント
  - `event_id`: イベントID
  - `event_name`: イベント名
  - `event_desc`: イベント説明
  - `event_addres`: 住所
  - `event_postalcode`: 郵便番号
  - `event_place`: 会場
  - `event_place_url`: 会場URL
  - `event_start_datetime`: 開始日時
  - `event_end_datetime`: 終了日時
  - `event_deadline_datetime`: 注文締切日時
  - `event_max_people`: 最大参加者数
  - `event_num_members`: 現在の参加者数
  - `event_payment`: 支払い方法（user_advance/user_on_day/community_bill）
  - `event_status`: イベントステータス
  - `event_cover_url`: イベントカバー画像
  - `organizer_company`: 主催者 会社名
  - `organizer_fullname`: 主催者 氏名
  - `organizer_email`: 主催者 メールアドレス
  - `organizer_memo`: 受け取りメモ
  - `organizer_phone_company`: 主催者 電話番号（会hさ）
  - `organizer_phone_personal`: 主催者 電話番号（個人）
  - `shop_id`: 注文する店舗ID
  - `shop_name`: 注文する店舗名
  - `partner_id`: 注文するパートナーID
  - `members`: 参加者リスト
  - `is_public`: 公開フラグ
  - `is_deleted`: 削除フラグ

#### イベントステータス
- `in_draft`: 下書き中
- `applying_reservation`: 予約申請中
- `applying_to_admin`: 管理者申請中
- `accepting_order`: 注文受付中
- `order_closed`: 注文締切
- `finished`: 終了
- `full`: 定員満員

### 2.3 ユーザー (FirestoredUser)
- システム利用者
- 主な属性：
  - `user_id`: ユーザーID
  - `user_name`: ユーザー名
  - `user_image_url`: プロフィール画像
  - `user_account`: アカウント名
  - `user_description`: 自己紹介
  - `user_sns_*`: SNS情報

### 2.4 店舗 (Shop)
- イベントで提供する飲食店
- 主な属性：
  - `shop_id`: 店舗ID
  - `shop_name`: 店舗名
  - `shop_description`: 店舗説明
  - `shop_genre`: ジャンル（弁当、和食、洋食など）
  - `shop_address`: 住所
  - `shop_address_latitude`: 緯度
  - `shop_address_longitude`: 軽度
  - `shop_time`: 営業時間
  - `shop_email`: 店舗メールアドレス
  - `shop_email_sub1`: 店舗メールアドレス(サブ1)
  - `shop_email_sub2`: 店舗メールアドレス(サブ2)
  - `shop_email_sub3`: 店舗メールアドレス(サブ3)
  - `shop_phone`: 電話番号
  - `shop_postcode`: 郵便番号
  - `shop_invoice_number`: 適格請求書発行事業者登録番号
  - `shop_url_*`:サイト情報・SNS情報 
  - `min_orders_on_spot`: 最小注文数
  - `shop_range_min_orders`: 配送範囲と最小注文数
  - `is_open`: 開店/閉店フラグ
  - `is_approved`: 運営承認フラグ

### 2.5 メニュー (PartnerMenu)
- 店舗が提供する商品
- 主な属性：
  - `menu_id`: メニューID
  - `menu_name`: メニュー名
  - `menu_price`: 価格
  - `menu_image_url`: 画像URL
  - `menu_description`: 説明
  - `menu_date_start`: 期間限定メニュー（開始日）
  - `menu_date_end`: 期間限定メニュー（終了日）
  - `is_soldout`: 売り切れフラグ

### 2.6 注文 (OrderItem)
- ユーザーの注文情報
- 主な属性：
  - `order_id`: 注文ID
  - `user_id`: ユーザーID
  - `event_id`: イベントID
  - `community_id`: コミュニティID
  - `status`: 注文ステータス（in_cart/ordered/canceled）
  - `menus`: 注文メニューリスト
  - `event_payment`: 支払い方法
  - `payment_intent`: Stripe決済ID

### 2.7 注文メニュー (OrderMenu)
- 注文に含まれる個別メニュー
- 主な属性：
  - `menu_id`: メニューID
  - `name`: メニュー名
  - `price`: 価格
  - `count`: 数量
  - `note`: 備考

## 7. 決済フロー

### 7.1 参加者事前決済
1. ユーザーがメニューを選択
2. カートに追加
3. Stripe決済実行
4. 注文確定

### 7.2 主催者請求書払い
1. ユーザーがメニューを選択
2. カートに追加
3. 注文確定（決済なし）
4. 主催者が後日請求書で支払い

#### Stripe統合
- 事前決済機能
- 決済意図（Payment Intent）管理
- エラーハンドリング
- セキュリティ対策

#### 支払い方法
1. **参加者事前決済（user_advance）**
   - 即座にStripe決済実行
   - 注文確定前に決済完了

2. **参加者当日払い（user_on_day）**
   - 決済なしで注文確定
   - 当日現金支払い

3. **主催者請求書払い（community_bill）**
   - 決済なしで注文確定
   - 主催者が後日請求書で支払い
