# 友人招待機能 仕様書

> **関連仕様**: 友人の定義・マイページ一覧・データスキーマ・一覧 API は [02_友人一覧機能.md](./02_友人一覧機能.md) を参照する。本仕様は**イベントへの招待**（注文完了後のメール送信）に焦点を当てる。

## 1. 機能概要

### 1.1 機能名
- 友人招待機能（たべとも招待）

### 1.2 機能概要
- 注文完了時に、同じ食事会へ**友人を誘う**（メールで最大10人まで送れる）
- 候補の並びは、ご一緒した回数の多い順（`GET /api/friends` のソート方針に準拠する想定）
- マイページの友人一覧定義（「一緒に食事会をした相手＝たべとも」）と一貫させる

### 1.3 名称検討
- 「友達」「友人」「ともだち」「友だち」「フレンド」「たべとも」
- **推奨**: 「たべとも」（食事 + 友達を表現し、ブランドアイデンティティに合致）

## 2. 技術仕様

### 2.1 フロントエンド実装
- **対象アプリ**: `/user/` (Vue 3 + Vite + Vuetify 3)
- **主要画面**: 注文完了モーダル
- **コンポーネント**:
  - `FriendInviteModal.vue` - 友人招待モーダル
- 招待候補の取得には、友人一覧と同じ Callable **`getUserFriends`** を利用する。リクエストでは **`target_user_id` にログイン中ユーザーの `user_id`（本人）を必須で渡す**（会う回数順など。詳細は [02_友人一覧機能.md](./02_友人一覧機能.md)）

### 2.2 バックエンド実装
- **Firebase Functions**: `/functions/default/` (TypeScript)
- **主要サービス**:
  - `inviteService.ts` - 招待メール送信
- 友人レコードの参照・検証に `friendsService.ts` を併用する想定

### 2.3 連携するデータ
- 友人の実体は `users/{userId}/friends/{friendUserId}`（友人一覧仕様のスキーマ）に従う
- 本機能では**招待送信**と**履歴**の記録（必要に応じて）を扱う

### 2.4 API仕様

#### 2.4.1 友人招待送信
```
POST /api/friends/invite
Request Body:
{
  eventId: string,
  friendUserIds: string[], // 最大10人
  customMessage?: string
}

Response:
{
  success: boolean,
  sentCount: number,
  errors: {
    userId: string,
    error: string
  }[]
}
```

## 3. 機能詳細

### 3.1 起動タイミング
- 注文完了モーダル内に「たべともを誘う」ボタンを配置
- ボタンクリックで招待モーダルを表示

### 3.2 招待モーダルの機能
- 友人一覧を表示（一緒に参加した回数順 ― 一覧 API のデフォルトソート想定）
- チェックボックスで複数選択（最大10人）
- カスタムメッセージ入力欄（任意）
- 送信ボタン

### 3.3 招待メール仕様
- **件名**: 「[Shokujii] {送信者名}さんから食事会のお誘い」
- **テンプレート**: SendGrid Dynamic Template使用
- **内容**:
  - 送信者名
  - イベント名
  - イベント日時・場所
  - カスタムメッセージ（あれば）
  - イベント詳細ページへのリンク

### 7.2 スパム対策
