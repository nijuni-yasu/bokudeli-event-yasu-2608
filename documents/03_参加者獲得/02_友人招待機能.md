# 友人招待機能 仕様書

## 1. 機能概要

### 1.1 機能名
- 友人招待機能（たべとも招待）

### 1.2 機能概要
- 「友人」をマイページに一覧表示する
- 「友人」とは「食事会（＝イベント）をご一緒したことのある人」。一度でも会ったら友達！
- 「食事でつながる」を実現したい。いつどこでお会いした人だっけ？を思い出しやすく。何回か会えば仲良くなる。
- 注文完了時に「友人を誘う」を行いたい。チェックボックスを入れて10人までメールで送信できる。並びはご一緒した回数の多い順。

### 1.3 名称検討
- 「友達」「友人」「ともだち」「友だち」「フレンド」「たべとも」
- **推奨**: 「たべとも」（食事 + 友達を表現し、ブランドアイデンティティに合致）

## 2. 技術仕様

### 2.1 フロントエンド実装
- **対象アプリ**: `/user/` (Vue 3 + Vite + Vuetify 3)
- **主要ページ**: マイページ、注文完了モーダル
- **コンポーネント**:
  - `FriendsList.vue` - 友人一覧表示
  - `FriendInviteModal.vue` - 友人招待モーダル
  - `FriendCard.vue` - 友人情報カード

### 2.2 バックエンド実装
- **Firebase Functions**: `/functions/default/` (TypeScript)
- **主要サービス**:
  - `friendsService.ts` - 友人関係管理
  - `inviteService.ts` - 招待メール送信
  - `batchService.ts` - 友人関係の一括更新

### 2.3 データベース設計

#### 2.3.1 推奨スキーマ: サブコレクション案
```
users/{userId}/friends/{friendUserId}
├── firstMetDate: Timestamp
├── lastMetDate: Timestamp
├── meetCount: number
├── eventHistory: string[] (イベントID配列)
├── createdAt: Timestamp
├── updatedAt: Timestamp
└── isActive: boolean
```

#### 2.3.2 配列案（代替案）
```
users/{userId}
├── friends: {
│   userId: string,
│   count: number,
│   firstMetDate: Timestamp,
│   lastMetDate: Timestamp
│ }[]
```

#### 2.3.3 推奨理由
- サブコレクション案を推奨する理由：
  - スケーラビリティ（ユーザー数増加に対応）
  - 詳細な履歴管理が可能
  - ページネーション対応
  - 個別の友人関係更新が効率的

### 2.4 API仕様

#### 2.4.1 友人一覧取得
```
GET /api/friends
Query Parameters:
- limit: number (default: 10)
- offset: number (default: 0)
- sortBy: 'meetCount' | 'lastMetDate' (default: 'meetCount')

Response:
{
  friends: {
    userId: string,
    displayName: string,
    photoURL: string,
    meetCount: number,
    lastMetDate: Timestamp,
    firstMetDate: Timestamp
  }[],
  hasMore: boolean,
  total: number
}
```

#### 2.4.2 友人招待送信
```
POST /api/friends/invite
Request Body:
{
  eventId: string,
  friendUserIds: string[], // 最大10人
  customMessage?: string
}

Response:
{
  success: boolean,
  sentCount: number,
  errors: {
    userId: string,
    error: string
  }[]
}
```

#### 2.4.3 友人関係更新（内部API）
```
POST /api/friends/update
Request Body:
{
  userId: string,
  friendUserId: string,
  eventId: string,
  action: 'add' | 'remove'
}
```

## 3. 機能詳細

### 3.1 友人一覧表示

#### 3.1.1 表示場所
- マイページに「たべとも」タブを追加
- タブ内に友人一覧を表示

#### 3.1.2 表示内容
- 友人のプロフィール写真
- 友人の表示名
- 一緒に参加した回数
- 最後に会った日
- 初めて会った日

#### 3.1.3 ソート・フィルタ
- デフォルト: 一緒に参加した回数の多い順
- 選択可能: 最後に会った日の新しい順
- ページネーション: 10件ずつ表示

### 3.2 友人招待機能

#### 3.2.1 起動タイミング
- 注文完了モーダル内に「たべともを誘う」ボタンを配置
- ボタンクリックで招待モーダルを表示

#### 3.2.2 招待モーダルの機能
- 友人一覧を表示（一緒に参加した回数順）
- チェックボックスで複数選択（最大10人）
- カスタムメッセージ入力欄（任意）
- 送信ボタン

#### 3.2.3 招待メール仕様
- **件名**: 「[Shokujii] {送信者名}さんから食事会のお誘い」
- **テンプレート**: SendGrid Dynamic Template使用
- **内容**:
  - 送信者名
  - イベント名
  - イベント日時・場所
  - カスタムメッセージ（あれば）
  - イベント詳細ページへのリンク
