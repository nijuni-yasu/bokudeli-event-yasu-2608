# フード注文なしのイベント無料参加

## 1. 概要

### 1.1 機能の目的
- 注文しないでイベントに参加することができる機能を提供し、主催者の参加者獲得を促進する。

### 1.2 主要な機能
- イベント作成時に「注文せずに参加する」オプションのON/OFF設定
- メニュー選択画面に「注文せずに参加する」ボタンの表示
- 無料参加者の注文データ作成（決済なし）
- 無料参加者への通知機能

### 1.3 対象ユーザー
- **主催者**: イベント作成時に無料参加オプションを設定
- **参加者**: 注文せずにイベントに参加したいユーザー

## 2. ねらい

### 2.1 ビジネス目標
- イベント参加者数の増加
- 主催者のイベント開催ハードルの低下
- コミュニティ活性化の促進

### 2.2 ユーザー価値
- **主催者**: より多くの参加者を獲得できる
- **参加者**: 注文の負担なくイベントに参加できる

### 2.3 成功指標（KPI）
- 無料参加オプション設定イベントの参加者数増加率
- 無料参加者の有料参加への転換率

## 3. 前提条件

### 3.1 技術的前提条件
- 既存のイベント管理システム
- 既存の注文管理システム
- 既存の通知システム

### 3.2 ビジネス的前提条件
- 主催者が無料参加を許可する設定
- 無料参加者もコミュニティメンバーとして扱う

### 3.3 依存関係
- イベント作成・編集機能
- 注文管理機能
- 通知機能
- コミュニティメンバー管理機能

## 4. 画面仕様

### 4.1 画面遷移
イベント作成・編集画面
├── 無料参加設定 → メニュー選択画面
└── メニュー選択画面
    ├── 通常注文 → カート画面
    └── 注文せずに参加 → 参加確認画面 → 参加完了画面

### 4.2 UI要素
- **イベント作成・編集画面**
  - 無料参加許可チェックボックス
  - 説明文: "注文せずに参加するオプションを表示する"

- **メニュー選択画面**
  - 「注文せずに参加する」ボタン（無料参加許可時のみ表示）
  - ボタン配置: メニュー一覧の最後

- **参加確認画面**
  - 無料参加の確認メッセージ
  - 参加確定ボタン
  - キャンセルボタン

## 5. 技術仕様・データ構造設計

### 5.1 Firestoreスキーマ
```typescript
// common/src/schemas/Event.ts
const EventDbSchema = z.object({
  // 既存フィールド...
  
  // 新規追加フィールド
  is_allow_free_participation: z.boolean().default(false),
})

// common/src/schemas/EventOrder.ts
const EventOrderDbSchema = z.object({
  // 既存フィールド（変更なし）
  order_id: z.string(),
  user_id: z.string(),
  event_id: z.string(),
  community_id: z.string(),
  community_account: z.string(),
  status: z.enum(['in_cart', 'ordered', 'canceled']),
  event_payment: z.string(),
  ordered_at: z.date().optional(),
  
  // 変更点
  menus: z.array(z.object({
    // メニュー情報
  })).optional(), // 無料参加の場合は空配列またはundefined
  
  // 新規追加フィールド
  is_free_participant: z.boolean().optional().default(false),
})
```

### 5.2 Firestoreフロントエンド処理
- **データ取得処理**: イベント情報取得時に`is_allow_free_participation`を取得
- **データ更新処理**: 無料参加注文作成時に`is_free_participant: true`を設定
- **リアルタイム監視**: 既存の注文監視機能を利用
- **エラーハンドリング**: 無料参加設定の不整合エラー処理

### 5.3 Firestoreセキュリティルール
変更点なし

### 5.4 Functions設計
#### 5.4.1 Callable Functions（フロントエンドから呼び出し）
- `createFreeParticipationOrder`: 無料参加注文作成
  - **引数**: `eventId: string`, `userId: string`
  - **戻り値**: `{ success: boolean, orderId: string }`
  - **認証**: 認証済みユーザーのみ

#### 5.4.2 Trigger Functions（自動実行）
- `onFreeParticipationOrderCreated`: 無料参加注文作成時の処理
  - **トリガー**: 無料参加注文作成時
  - **処理内容**: コミュニティメンバー追加、通知送信
  - **権限**: Functions実行権限

### 5.5 処理フロー
1. 主催者がイベント作成・編集時に無料参加許可を設定
2. 参加者がメニュー選択画面で「注文せずに参加する」を選択
3. カート画面（参加確認画面）で「無料参加」にて「確定」ボタンを押下
4. Callable Function `createFreeParticipationOrder`を呼び出し
5. 無料参加注文データをFirestoreに保存（`is_free_participant: true`, `menus: []`）
6. Trigger Function `onFreeParticipationOrderCreated`が自動実行
7. コミュニティメンバーに追加
8. 参加者に通知メール送信
9. 参加完了画面を表示

## 7. 注意事項

### 7.1 既存システムへの影響
- **イベント管理**: 既存のイベント作成・編集機能に設定項目を追加
- **注文管理**: 既存の注文データ構造に無料参加フラグを追加
- **通知システム**: 既存の通知機能を無料参加者にも適用
- **コミュニティ管理**: 既存のメンバー管理機能を無料参加者にも適用

### 7.2 セキュリティ考慮事項
- **認証**: 無料参加注文作成時も認証チェックを必須とする
- **権限**: イベント主催者のみが無料参加設定を変更可能
- **データ整合性**: 無料参加注文と通常注文の整合性チェック
- **不正利用防止**: 同一ユーザーの重複無料参加防止

### 7.3 運用考慮事項
- **通知**: 無料参加者にも通常の参加者と同様の通知を送信
  - 注文完了メール
  - イベント直前リマインドメール
  - イベント終了メール
- **統計**: 無料参加者の参加状況を適切に記録・分析
- **サポート**: 無料参加に関する問い合わせ対応
- **パフォーマンス**: 無料参加者の大量参加時の処理負荷考慮
- **マイページ表示**: 無料参加者もマイページに参加イベント一覧を表示
- **キャンセル機能**: 無料参加者もイベントキャンセルを実行可能
