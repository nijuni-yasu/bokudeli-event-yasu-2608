# 廃案
/events/{eventId}/free_participations/{userId} のドキュメントを作成する案は廃案。
メール配信、slack通知など影響範囲が大きいため。
既存の events/{eventId}/orders/{orderId} のドキュメントをつかう。


# 注文なしでのイベント参加

## 1. 概要

### 1.1 機能の目的
注文しないでイベントに参加することができる機能を提供し、主催者の参加者獲得を促進する。

### 1.2 主要な機能
- メニュー選択画面に「注文せずに参加する」オプションを表示
- 主催者がイベント作成時に「注文せずに参加する」機能のON/OFF設定
- 注文なし参加者の専用データ構造での管理
- 決済処理なしでのイベント参加

### 1.3 対象ユーザー
- **主催者**: イベント作成時に注文なし参加機能の設定
- **参加者**: 注文せずにイベントに参加したいユーザー

## 2. ねらい

### 2.1 ビジネス目標
- イベント参加者の増加率向上（目標：10%増）
- 主催者のイベント満足度向上
- コミュニティ活性化の促進

### 2.2 ユーザー価値
- **主催者**: より多くの参加者を獲得できる
- **参加者**: 注文の負担なくイベントに参加できる

### 2.3 成功指標（KPI）
- 注文なし参加者の利用率
- イベント全体の参加者数増加率
- 主催者の機能満足度

## 3. 前提条件

### 3.1 技術的前提条件
- 既存のイベント参加システムが正常に動作していること
- Firestoreのセキュリティルールが適切に設定されていること
- 認証システムが正常に動作していること

### 3.2 ビジネス的前提条件
- 主催者が注文なし参加を許可する設定が可能であること
- 注文なし参加者もイベントの参加者としてカウントされること

### 3.3 依存関係
- イベント管理機能
- ユーザー認証機能
- 参加者管理機能

## 4. 画面仕様

#### 注文なし参加者スキーマ（新規）
```typescript
// common/src/schemas/EventFreeParticipation.ts
import { z } from 'zod'

const EventFreeParticipationDbSchema = z.object({
  // 必須フィールド
  event_id: z.string(),
  user_id: z.string(),
  community_id: z.string(),
  community_account: z.string(),
  
  // 参加情報
  joined_at: z.date(),
  
  // タイムスタンプ
  created_at: z.date(),
  updated_at: z.date(),
})

// クラス定義
export class EventFreeParticipation {
  event_id: string = ''
  user_id: string = ''
  community_id: string = ''
  community_account: string = ''
  joined_at: Date = new Date()
  created_at: Date = new Date()
  updated_at: Date = new Date()
  
  // バリデーション
  validate(): boolean {
    return this.event_id.length > 0 && this.user_id.length > 0
  }
  
  // ファクトリメソッド
  static fromDb(data: any, userId: string): EventFreeParticipation {
    const participation = new EventFreeParticipation()
    participation.event_id = data.event_id
    participation.user_id = userId // パスから取得したuserIdを使用
    participation.community_id = data.community_id
    participation.community_account = data.community_account
    participation.joined_at = data.joined_at.toDate()
    participation.created_at = data.created_at.toDate()
    participation.updated_at = data.updated_at.toDate()
    return participation
  }
}
```

```typescript
const getFreeParticipations = async (eventId: string) => {

// ユーザーの注文なし参加状況確認
const getUserFreeParticipation = async (eventId: string, userId: string) => {
  const docRef = doc(db, 'events', eventId, 'free_participations', userId)
  const docSnap = await getDoc(docRef)
  return docSnap.exists() ? EventFreeParticipation.fromDb(docSnap.data(), userId) : null
}
```

#### データ更新処理
```typescript
// 注文なし参加の登録
const createFreeParticipation = async (eventId: string, participation: EventFreeParticipation) => {
  const docRef = doc(db, 'events', eventId, 'free_participations', participation.user_id)
  participation.created_at = new Date()
  participation.updated_at = new Date()
  
  await setDoc(docRef, participation)
  return participation
}

// イベントの注文なし参加設定更新
const updateEventFreeParticipationSetting = async (eventId: string, allowFreeParticipation: boolean) => {
  const eventRef = doc(db, 'events', eventId)
  await updateDoc(eventRef, {
    is_allow_free_participation: allowFreeParticipation,
    updated_at: new Date()
  })
}
```

#### リアルタイム監視
```typescript
// 注文なし参加者のリアルタイム監視
const watchFreeParticipations = (eventId: string, callback: (participations: EventFreeParticipation[]) => void) => {
  const q = query(
    collection(db, 'events', eventId, 'free_participations'),
    orderBy('joined_at', 'desc')
  )
  
  return onSnapshot(q, (snapshot) => {
    const participations = snapshot.docs.map(doc => 
      EventFreeParticipation.fromDb(doc.data(), doc.id)
    )
    callback(participations)
  })
}
```

### 5.3 Firestoreセキュリティルール
```javascript
// firestore.rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 注文なし参加者のアクセス制御
    match /events/{eventId}/free_participations/{userId} {
      allow read: if request.auth != null && (
        // イベント参加者（自分自身の参加情報）
        userId == request.auth.uid ||
        // コミュニティ管理者
        exists(/databases/$(database)/documents/communities/$(resource.data.community_id)/members/$(request.auth.uid)) ||
        // サポートアカウント
        request.auth.uid in get(/databases/$(database)/documents/configs/global).data.support_user_ids
      );
      
      allow create: if request.auth != null && 
        userId == request.auth.uid &&
        // イベントが注文なし参加を許可している
        get(/databases/$(database)/documents/events/$(eventId)).data.is_allow_free_participation == true;
      
      allow update, delete: if false; // 作成後の変更は不可
    }
  }
}
```

### 5.4 Functions設計

#### 5.4.1 Callable Functions（フロントエンドから呼び出し）
- `createFreeParticipation`: 注文なし参加の登録
  - **引数**: `eventId: string`, `userId: string`
  - **戻り値**: `{ success: boolean, user_id: string }`
  - **認証**: 認証済みユーザーのみ

- `updateEventFreeParticipationSetting`: イベントの注文なし参加設定更新
  - **引数**: `eventId: string`, `allowFreeParticipation: boolean`
  - **戻り値**: `{ success: boolean }`
  - **認証**: コミュニティ管理者のみ

#### 5.4.2 Trigger Functions（自動実行）
- `onFreeParticipationCreated`: 注文なし参加登録時の自動処理
  - **トリガー**: `events/{eventId}/free_participations/{userId}` 作成時
  - **処理内容**: 
    - イベント参加者数の更新
    - 主催者への通知送信
    - 参加者への確認メール送信
  - **権限**: Functions実行権限

### 5.5 処理フロー

#### 注文なし参加の処理フロー
1. ユーザーがメニュー選択画面で「注文せずに参加する」をクリック
2. フロントエンドでイベントの注文なし参加許可設定を確認
3. Callable Function `createFreeParticipation`を呼び出し
4. Firebase Functionで認証チェック
5. イベントの注文なし参加許可設定を確認
6. 既存の注文なし参加がないかチェック
7. Firestoreに注文なし参加データを保存
8. Trigger Function `onFreeParticipationCreated`が自動実行
9. イベント参加者数を更新
10. 主催者に通知送信
11. 参加者に確認メール送信
12. レスポンスをフロントエンドに返却
13. フロントエンドで参加完了画面を表示

#### イベント設定更新の処理フロー
1. 主催者がイベント編集画面で注文なし参加設定を変更
2. フロントエンドで設定変更の確認
3. Callable Function `updateEventFreeParticipationSetting`を呼び出し
4. Firebase Functionで認証・権限チェック
5. Firestoreのイベントデータを更新
6. レスポンスをフロントエンドに返却
7. フロントエンドで設定完了メッセージを表示
