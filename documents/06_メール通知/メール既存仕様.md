# メール通知機能

## 1. 概要

### 1.1 機能の目的
bokudeli-event-newシステムにおいて、主催者、参加者、飲食店に対して適切なタイミングでメール通知を送信し、イベントの円滑な運営とユーザー体験の向上を図る。

### 1.2 技術仕様
- **メール配信サービス**: SendGrid
- **テンプレート管理**: SendGrid Dynamic Templates
- **送信元アドレス**: システム統一アドレス（DEFAULT_FROM）
- **返信先アドレス**: コミュニティメールアドレス（Reply-To）

## 2. 主催者向けメール通知

### 2.1 イベント作成・管理関連

#### 2.1.1 イベント作成完了通知
- **タイミング**: イベント作成完了時
- **内容**:
  - イベント名、日時、場所の確認
  - 次のステップ（予約申請、参加者募集等）の案内
  - イベント管理画面へのリンク
- **送信先**: 主催者メールアドレス

#### 2.1.2 予約申請送信通知
- **タイミング**: イベントステータスが`applying_reservation`に変更時
- **内容**:
  - 予約申請の送信完了
  - 飲食店からの承認待ち状況
  - 承認までの予想時間
- **送信先**: 主催者メールアドレス

#### 2.1.3 予約承認・拒否通知
- **タイミング**: 飲食店からの予約承認・拒否時
- **内容**:
  - 承認の場合：注文受付開始の案内
  - 拒否の場合：理由と代替案の提示
- **送信先**: 主催者メールアドレス

### 2.2 注文・決済関連

#### 2.2.1 注文締切リマインダー
- **タイミング**: 注文締切1日前
- **内容**:
  - 注文締切日の確認
  - 現在の注文状況
  - 参加者への催促案内
- **送信先**: 主催者メールアドレス

#### 2.2.2 注文締切通知
- **タイミング**: 注文締切時刻
- **内容**:
  - 注文締切の完了
  - 最終注文状況のサマリー
  - 飲食店への注文確定通知
- **送信先**: 主催者メールアドレス

#### 2.2.3 請求書発行通知（主催者請求書払いの場合）
- **タイミング**: イベント終了後
- **内容**:
  - 請求書の作成完了
  - 請求金額の詳細
  - 支払い期限と方法
  - 請求書ダウンロードリンク
- **送信先**: 主催者メールアドレス

#### 2.2.4 支払い期限リマインダー
- **タイミング**: 支払い期限の1日、5日、10日、20日、30日、40日、50日、60日前
- **内容**:
  - 支払い期限の確認
  - 未払い金額の詳細
  - 支払い方法の案内
- **送信先**: 主催者メールアドレス

### 2.3 イベント運営関連

#### 2.3.1 イベント開始前リマインダー
- **タイミング**: イベント開始1日前
- **内容**:
  - イベント詳細の最終確認
  - 参加者数と注文状況
  - 当日の注意事項
- **送信先**: 主催者メールアドレス

#### 2.3.2 イベント終了通知
- **タイミング**: イベント終了後
- **内容**:
  - イベント完了の確認
  - 参加者数と注文実績
  - 次回イベントの案内
- **送信先**: 主催者メールアドレス

### 2.4 コミュニティ管理関連

#### 2.4.1 コミュニティ作成完了通知
- **タイミング**: コミュニティ作成完了時
- **内容**:
  - コミュニティ名とアカウントの確認
  - 管理画面へのアクセス方法
  - 次のステップの案内
- **送信先**: コミュニティ管理者メールアドレス

#### 2.4.2 管理者招待通知
- **タイミング**: 新しい管理者が招待された時
- **内容**:
  - 招待者の情報
  - 招待URL
  - 招待の有効期限
- **送信先**: 招待された管理者のメールアドレス

#### 2.4.3 管理者権限変更通知
- **タイミング**: 管理者権限の追加・削除時
- **内容**:
  - 権限変更の内容
  - 変更理由（オプション）
  - サポート連絡先
- **送信先**: 対象管理者のメールアドレス

## 3. 参加者向けメール通知

### 3.1 イベント参加関連

#### 3.1.1 イベント参加確認
- **タイミング**: 注文完了時
- **内容**:
  - イベント名、日時、場所の確認
  - 注文内容の詳細
  - イベントページへのリンク
  - カレンダー予定（.icsファイル添付）
- **送信先**: 参加者メールアドレス

#### 3.1.2 注文締切リマインダー
- **タイミング**: 注文締切1日前
- **内容**:
  - 注文締切日の確認
  - 未注文の場合の催促
  - イベントページへのリンク
- **送信先**: 未注文の参加者メールアドレス

#### 3.1.3 イベント開始前リマインダー
- **タイミング**: イベント開始1日前
- **内容**:
  - イベント詳細の最終確認
  - 注文内容の確認
  - 当日の注意事項
- **送信先**: 参加者メールアドレス

#### 3.1.4 イベント終了通知
- **タイミング**: イベント終了後
- **内容**:
  - イベント参加のお礼
  - 次回イベントの案内
  - アンケートへの協力依頼
- **送信先**: 参加者メールアドレス

### 3.2 注文・決済関連

#### 3.2.1 注文完了通知（事前決済の場合）
- **タイミング**: Stripe決済完了時
- **内容**:
  - 決済完了の確認
  - 注文内容の詳細
  - 領収書のダウンロードリンク
- **送信先**: 参加者メールアドレス

#### 3.2.2 カート未完了リマインダー
- **タイミング**: カートに商品がある状態で24時間経過
- **内容**:
  - 未完了注文の案内
  - 注文完了への誘導
  - イベントページへのリンク
- **送信先**: 参加者メールアドレス

#### 3.2.3 注文キャンセル通知
- **タイミング**: 注文キャンセル時
- **内容**:
  - キャンセルの確認
  - 返金手続きの案内（事前決済の場合）
  - 再注文への誘導
- **送信先**: 参加者メールアドレス

### 3.3 コミュニティ関連

#### 3.3.1 コミュニティ参加確認
- **タイミング**: コミュニティ参加時
- **内容**:
  - コミュニティ名の確認
  - コミュニティページへのリンク
  - 今後のイベント案内
- **送信先**: 参加者メールアドレス

#### 3.3.2 新イベント案内
- **タイミング**: 参加コミュニティで新イベント作成時
- **内容**:
  - 新イベントの概要
  - イベントページへのリンク
  - 早期申込の案内
- **送信先**: コミュニティメンバーのメールアドレス

## 4. 飲食店向けメール通知

### 4.1 予約申請関連

#### 4.1.1 予約申請受信通知
- **タイミング**: イベントステータスが`applying_reservation`に変更時
- **内容**:
  - イベント詳細（日時、場所、参加予定人数）
  - 主催者情報
  - 承認・拒否の選択肢
  - 管理画面へのリンク
- **送信先**: 店舗メールアドレス（複数登録可）

#### 4.1.2 予約申請リマインダー
- **タイミング**: 予約申請から1日後
- **内容**:
  - 未回答の予約申請の案内
  - 承認・拒否の催促
  - 管理画面へのリンク
- **送信先**: 店舗メールアドレス

#### 4.1.3 予約申請自動却下通知
- **タイミング**: 予約申請から2日後（48時間・未回答の場合）
- **内容**:
  - 自動却下の通知
  - 却下理由の説明
  - 今後の対応方法
- **送信先**: 店舗メールアドレス

### 4.2 注文管理関連

#### 4.2.1 注文締切リマインダー
- **タイミング**: 注文締切1日前
- **内容**:
  - 注文締切日の確認
  - 現在の注文状況
  - 準備の確認事項
- **送信先**: 店舗メールアドレス

#### 4.2.2 注文確定通知
- **タイミング**: 注文締切時刻
- **内容**:
  - 最終注文内容の詳細
  - 配達・受取時刻の確認
  - 主催者連絡先情報
- **送信先**: 店舗メールアドレス

#### 4.2.3 新規注文通知
- **タイミング**: 新規注文受信時
- **内容**:
  - 注文内容の詳細
  - 注文者情報
  - 管理画面での確認方法
- **送信先**: 店舗メールアドレス

### 4.3 売上・決済関連

#### 4.3.1 売上レポート
- **タイミング**: イベント終了後
- **内容**:
  - 売上金額の詳細
  - 注文内容の内訳
  - 手数料の計算
  - 振込予定日
- **送信先**: 店舗メールアドレス

#### 4.3.2 振込完了通知
- **タイミング**: 売上振込完了時
- **内容**:
  - 振込金額の確認
  - 振込日
  - 次回振込予定
- **送信先**: 店舗メールアドレス

## 5. システム全体向けメール通知

### 5.1 アカウント管理関連

#### 5.1.1 アカウント作成確認
- **タイミング**: 新規ユーザー登録時
- **内容**:
  - アカウント作成の確認
  - メールアドレス認証の案内
  - 利用開始の手順
- **送信先**: 新規ユーザーのメールアドレス

#### 5.1.2 パスワードリセット
- **タイミング**: パスワードリセット要求時
- **内容**:
  - リセット用のパスコード
  - リセット手順の案内
  - セキュリティの注意事項
- **送信先**: ユーザーのメールアドレス

### 5.2 お知らせ配信

#### 5.2.1 コミュニティお知らせ
- **タイミング**: コミュニティ管理者がお知らせを送信時
- **内容**:
  - お知らせのタイトルと内容
  - コミュニティ名
  - 返信先アドレス
- **送信先**: コミュニティメンバーのメールアドレス

#### 5.2.2 イベント参加者向けお知らせ
- **タイミング**: イベント主催者がお知らせを送信時
- **内容**:
  - お知らせのタイトルと内容
  - イベント名
  - 返信先アドレス
- **送信先**: イベント参加者のメールアドレス

#### 5.2.3 システムお知らせ
- **タイミング**: システムメンテナンス、機能追加等
- **内容**:
  - お知らせの内容
  - 影響範囲
  - 対応方法
- **送信先**: 全ユーザーのメールアドレス

## 6. メール通知の設定・管理

### 6.1 通知設定
- **ユーザー設定**: 各ユーザーが受信したい通知の種類を選択可能
- **コミュニティ設定**: コミュニティ管理者がメンバーへの通知設定を管理
- **店舗設定**: 店舗が受信したい通知の種類を選択可能

### 6.2 配信制御
- **配信停止**: ユーザーが配信停止を要求した場合の処理
- **配信再開**: 配信停止後の再開手続き
- **配信エラー**: 配信失敗時の再送処理

### 6.3 配信ログ
- **配信履歴**: 送信したメールの履歴管理
- **配信統計**: 配信率、開封率、クリック率の統計
- **エラーログ**: 配信エラーの詳細ログ
