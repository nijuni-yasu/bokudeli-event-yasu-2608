
# メール_主催者_新着飲食店通知

## 1. 概要
### 1.1 機能の目的
新規オープンした飲食店の情報を主催者に通知し、イベント企画の選択肢を増やすことで、主催者の利便性向上と飲食店の露出機会創出を図る。

### 1.2 主要な機能
- 新規オープン飲食店の自動検出
- 配送範囲に基づく主催者への絞り込み配信
- 飲食店情報（店舗名、URL等）の通知
- 配信済みフラグによる重複配信防止

### 1.3 対象ユーザー
- コミュニティ管理者（主催者）
- 新規オープンした飲食店

## 2. ねらい
### 2.1 ビジネス目標
- 主催者のイベント企画選択肢の拡大
- 新規飲食店の露出機会創出
- プラットフォーム利用頻度の向上

### 2.2 ユーザー価値
- 主催者：新規飲食店の発見によるイベント企画の多様化
- 飲食店：新規オープン時の露出機会獲得

### 2.3 成功指標（KPI）
- 新規飲食店通知の開封率
- 通知からイベント作成への転換率
- 新規飲食店のイベント参加率

## 3. 前提条件
### 3.1 技術的前提条件
- PartnerShopドキュメントの`is_open`、`is_approved`フィールドが存在
- 配送範囲計算機能が実装済み
- メール配信機能（SendGrid）が利用可能

### 3.2 ビジネス的前提条件
- 飲食店の公開承認プロセスが完了している
- コミュニティの郵便番号情報が登録済み

### 3.3 依存関係
- PartnerShop管理機能
- 配送範囲計算機能
- メール配信機能

```typescript
// functions/default/src/scheduled/sendNewShopNotifications.ts
export const sendNewShopNotifications = onSchedule(
  '0 10 * * *',  // 毎日午前10時実行
  async () => {
    console.log('Starting new shop notification process...');
    
    try {
      // 1. 新規飲食店を検索
      const newShops = await getNewShopsForNotification();
      
      // 2. 各飲食店について配送範囲内のコミュニティを検索
      for (const shop of newShops) {
        const targetCommunities = await getCommunitiesInDeliveryRange(shop);
        
        // 3. 各コミュニティにメール配信
        for (const community of targetCommunities) {
          await sendNewShopNotificationEmail(shop, community);
        }
        
        // 4. 配信済みフラグを更新
        await updateSentFlag(shop.shop_id);
      }
      
      console.log(`New shop notification completed: ${newShops.length} shops processed`);
    } catch (error) {
      console.error('New shop notification failed:', error);
    }
  }
);
```

### 5.5 処理フロー
#### 5.5.1 自動配信処理フロー
```markdown
### 新着飲食店通知の自動配信フロー
1. Scheduled Function `sendNewShopNotifications`が毎日午前10時に実行
2. 新規オープン飲食店を検索（`is_open: true`, `is_approved: true`, `is_sent_mail_new_shop_at`がnullまたは存在しない）
3. 各飲食店について配送範囲内のコミュニティを検索
4. 配送範囲計算（店舗の緯度・経度からコミュニティの郵便番号までの距離）
5. 配送範囲内のコミュニティ管理者にメール配信
6. 配信完了後、`is_sent_mail_new_shop_at`に現在時刻を設定
7. 処理結果をログに記録
```



### 5.6 配送範囲計算ロジック
```typescript
// 配送範囲計算関数
const calculateDistance = (lat1: number, lon1: number, lat2: number, lon2: number): number => {
  const R = 6371; // 地球の半径（km）
  const dLat = (lat2 - lat1) * Math.PI / 180;
  const dLon = (lon2 - lon1) * Math.PI / 180;
  const a = Math.sin(dLat/2) * Math.sin(dLat/2) +
    Math.cos(lat1 * Math.PI / 180) * Math.cos(lat2 * Math.PI / 180) *
    Math.sin(dLon/2) * Math.sin(dLon/2);
  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
  return R * c;
};

// 配送範囲内のコミュニティ検索
const getCommunitiesInDeliveryRange = async (shop: PartnerShop) => {
  const communities = await db.collection('communities').get();
  const targetCommunities = [];
  
  for (const communityDoc of communities.docs) {
    const community = communityDoc.data();
    if (!community.community_postalcode) continue;
    
    // 郵便番号から緯度・経度を取得（外部APIまたはローカルDB）
    const postalCodeCoords = await getCoordinatesFromPostalCode(community.community_postalcode);
    
    // 配送範囲内かチェック
    const distance = calculateDistance(
      shop.shop_address_latitude,
      shop.shop_address_longitude,
      postalCodeCoords.latitude,
      postalCodeCoords.longitude
    );
    
    // 最大配送範囲を取得
    const maxRange = Math.max(...shop.shop_range_min_orders.map(r => r.range_km));
    
    if (distance <= maxRange) {
      targetCommunities.push(community);
    }
  }
  
  return targetCommunities;
};
```

### 6.2 マイグレーション実装
```typescript
// functions/default/src/migrations/addNewShopNotificationFlag.ts
export const addNewShopNotificationFlag = onCall(async (request) => {
  const uid = request.auth?.uid;
  if (uid == null) {
    throw new HttpsError('unauthenticated', '認証が必要です');
  }
  
  // 管理者権限チェック
  const user = await getAdminUser(uid);
  if (!user.is_admin) {
    throw new HttpsError('permission-denied', '管理者権限が必要です');
  }
  
  try {
    const batch = db.batch();
    const snapshot = await db.collectionGroup('shops').get();
    
    snapshot.docs.forEach((doc) => {
      const data = doc.data();
      
      // is_sent_mail_new_shop_atフィールドが存在しない場合のみ追加
      if (data.is_sent_mail_new_shop_at === undefined) {
        batch.update(doc.ref, {
          is_sent_mail_new_shop_at: null,
          updated_at: new Date()
        });
      }
    });
    
    await batch.commit();
    
    return {
      success: true,
      updated_count: snapshot.docs.length
    };
  } catch (error) {
    console.error('Migration failed:', error);
    throw new HttpsError('internal', 'マイグレーション処理に失敗しました');
  }
});
```

# 要求仕様
- 飲食店公開タイミングで、主催者全体に通知する
- 飲食店のPartnerShopドキュメントが `is_open`:`true` かつ`is_approved`:`true` かつ `is_sent_mail_new_shop_at` : `null`またはフィールドなし のタイミングでコミュニティに対して配信する
- 飲食店の配送設定の中心地(緯度・経度)からの配送距離の中に、コミュニティの郵便番号が存在している場合に送信する
- 送信内容は「飲食店名」「飲食店URL」などの情報
- これまでオープンになっている飲食店については、配信しない。 `is_sent_mail_new_shop_at` : `timestamp`にバッチ処理をしておく。
