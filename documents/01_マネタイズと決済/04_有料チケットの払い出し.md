# 有料チケットの払い出し

## 1. 概要

### 1.1 機能の目的
イベント主催者に対して、有料チケットの販売代金をStripe Connectを使用して自動的に支払いする機能を提供する。

### 1.2 主要な機能
- 有料チケット販売代金の自動計算
- Stripe Connectによる主催者への支払い処理
- システム利用料の自動控除
- 支払い履歴の管理・表示
- 支払い状況の通知機能

### 1.3 対象ユーザー
- **主催者**: 有料チケットを販売するイベント主催者（コミュニティ管理者）
- **運営**: 支払い処理を管理するシステム運営者

#### 5.1.2 イベント支払いスキーマ
**ドキュメントパス**: `/communities/{communityId}/events/{eventId}/payments/{paymentId}`

```typescript
// common/src/schemas/EventPayment.ts
import { z } from 'zod'

const EventPaymentDbSchema = z.object({
  // 基本情報
  payment_id: z.string(),
  event_id: z.string(),
  community_id: z.string(),
  
  // 支払い情報
  payment_amount: z.number().min(0),           // 支払い金額（システム利用料控除後）
  system_fee_total: z.number().min(0),         // システム利用料合計
  gross_amount: z.number().min(0),             // 総売上（システム利用料含む）
  
  // チケット別内訳
  ticket_breakdown: z.array(z.object({
    ticket_id: z.string(),
    ticket_name: z.string(),
    ticket_price: z.number(),
    sold_quantity: z.number(),
    subtotal: z.number(),
    system_fee: z.number(),
  })),
  
  // Stripe Connect情報
  stripe_account_id: z.string(),               // 主催者のStripe ConnectアカウントID
  stripe_transfer_id: z.string().optional(),   // Stripe転送ID
  stripe_payout_id: z.string().optional(),     // Stripe支払いID
  
  // 支払いステータス
  payment_status: z.enum([
    'pending',      // 支払い待ち
    'processing',   // 支払い処理中
    'completed',    // 支払い完了
    'failed',       // 支払い失敗
    'cancelled'     // 支払いキャンセル
  ]),
  
  // 支払い日時
  payment_scheduled_at: z.date(),              // 支払い予定日
  payment_processed_at: z.date().optional(),   // 支払い処理日
  payment_completed_at: z.date().optional(),   // 支払い完了日
  
  // タイムスタンプ
  created_at: z.date(),
  updated_at: z.date(),
})

export class EventPayment {
  payment_id: string = ''
  event_id: string = ''
  community_id: string = ''
  payment_amount: number = 0
  system_fee_total: number = 0
  gross_amount: number = 0
  ticket_breakdown: Array<{
    ticket_id: string
    ticket_name: string
    ticket_price: number
    sold_quantity: number
    subtotal: number
    system_fee: number
  }> = []
  stripe_account_id: string = ''
  stripe_transfer_id?: string
  stripe_payout_id?: string
  payment_status: 'pending' | 'processing' | 'completed' | 'failed' | 'cancelled' = 'pending'
  payment_scheduled_at: Date = new Date()
  payment_processed_at?: Date
  payment_completed_at?: Date
  created_at: Date = new Date()
  updated_at: Date = new Date()
  
  // 支払い可能チェック
  canProcessPayment(): boolean {
    return this.payment_status === 'pending' && 
           this.payment_amount > 0 &&
           this.stripe_account_id.length > 0
  }
  
  // 支払い完了チェック
  isCompleted(): boolean {
    return this.payment_status === 'completed'
  }
  
  // ファクトリメソッド
  static fromDb(data: any): EventPayment {
    const payment = new EventPayment()
    payment.payment_id = data.payment_id
    payment.event_id = data.event_id
    payment.community_id = data.community_id
    payment.payment_amount = data.payment_amount
    payment.system_fee_total = data.system_fee_total
    payment.gross_amount = data.gross_amount
    payment.ticket_breakdown = data.ticket_breakdown || []
    payment.stripe_account_id = data.stripe_account_id
    payment.stripe_transfer_id = data.stripe_transfer_id
    payment.stripe_payout_id = data.stripe_payout_id
    payment.payment_status = data.payment_status
    payment.payment_scheduled_at = data.payment_scheduled_at.toDate()
    payment.payment_processed_at = data.payment_processed_at?.toDate()
    payment.payment_completed_at = data.payment_completed_at?.toDate()
    payment.created_at = data.created_at.toDate()
    payment.updated_at = data.updated_at.toDate()
    return payment
  }
}
```

### 5.4 Functions設計

#### 5.4.1 Callable Functions（フロントエンドから呼び出し）
- `setupStripeConnect`: Stripe Connectアカウント設定
  - **引数**: `communityId: string`, `stripeAccountData: StripeAccountData`
  - **戻り値**: `{ success: boolean, account_id: string }`
  - **認証**: コミュニティ管理者のみ

- `getPaymentStatus`: 支払い状況取得
  - **引数**: `eventId: string`
  - **戻り値**: `{ payment: EventPayment | null }`
  - **認証**: コミュニティ管理者のみ

- `getPaymentHistory`: 支払い履歴取得
  - **引数**: `communityId: string`, `limit: number`, `offset: number`
  - **戻り値**: `{ payments: EventPayment[], total: number }`
  - **認証**: コミュニティ管理者のみ

- `processPaymentManually`: 手動支払い実行（運営用）
  - **引数**: `paymentId: string`
  - **戻り値**: `{ success: boolean, transfer_id: string }`
  - **認証**: システム管理者のみ

#### 5.4.2 Trigger Functions（自動実行）
- `onEventFinished`: イベント終了時の支払い計算
  - **トリガー**: イベントステータスが「finished」に変更された時
  - **処理内容**: 支払い金額の計算、支払い情報の作成
  - **権限**: システム権限

- `onPaymentScheduled`: 支払い予定日の自動支払い処理
  - **トリガー**: 支払い予定日になった時
  - **処理内容**: Stripe Connectによる自動支払い実行
  - **権限**: システム権限

- `onStripeTransferCompleted`: Stripe転送完了時の処理
  - **トリガー**: Stripe Webhook（transfer.created）
  - **処理内容**: 支払いステータスの更新、通知送信
  - **権限**: システム権限

#### 5.4.3 Scheduled Functions（定期実行）
- `scheduledPaymentProcessing`: 定期支払い処理
  - **スケジュール**: 毎日午前9時に実行
  - **処理内容**: 支払い予定日の支払い処理実行
  - **権限**: システム権限

### 5.5 処理フロー

#### 5.5.1 支払い計算・作成フロー
1. イベントが「終了」ステータスに変更される
2. Trigger Function `onEventFinished`が自動実行
3. 有料チケットの販売状況を集計
4. システム利用料を計算
5. 支払い金額を計算（総売上 - システム利用料）
6. 支払い予定日を設定（イベント終了日 + 設定日数）
7. 支払い情報をFirestoreに保存
8. 主催者に支払い予定通知を送信

#### 5.5.2 自動支払い処理フロー
1. 支払い予定日になった時
2. Trigger Function `onPaymentScheduled`が自動実行
3. Stripe Connectアカウントの有効性を確認
4. 支払いステータスを「processing」に更新
5. Stripe Connect APIで転送処理を実行
6. 転送IDを保存
7. 支払いステータスを「completed」に更新
8. 主催者に支払い完了通知を送信

#### 5.5.3 Stripe Webhook処理フロー
1. Stripeから転送完了Webhookを受信
2. Trigger Function `onStripeTransferCompleted`が実行
3. Webhookの署名を検証
4. 転送IDに対応する支払い情報を取得
5. 支払いステータスを更新
6. 必要に応じて追加処理を実行
