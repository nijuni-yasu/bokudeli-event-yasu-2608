# 無料参加・割引参加・クーポン機能

## 1. 概要

### 1.1 機能の目的
イベント主催者が参加者に対して「無料参加」「割引参加」「クーポン参加」のいずれかの割引設定を行える機能を提供し、参加者の参加障壁を下げてイベントの集客を促進する。

### 1.2 主要な機能
- 無料参加設定：参加費を全額主催者が負担し、参加者は¥0で参加可能
- 割引参加設定：一部金額を主催者が負担し、残額を参加者が支払う
- クーポン設定：条件を満たす参加者に対してクーポン割引を適用（コード入力式）
- 割引タイプ別の表示制御：イベントカードや、イベントページでのラベル表示、決済画面での価格表示
- 主催者への請求書：無料参加、割引参加、クーポンで割引いた金額は、主催者請求書機能において請求する。

### 1.3 対象ユーザー
- イベント主催者：割引設定を行う側
- イベント参加者：割引を利用する側

## 2. ねらい

### 2.1 ビジネス目標
- イベント参加率の向上
- 新規参加者の獲得促進
- 主催者のイベント運営コスト最適化

### 2.2 ユーザー価値
- 主催者：参加者の参加障壁を下げて集客効果を向上
- 参加者：経済的負担を軽減してイベント参加を促進
- 学生や経済的制約のある参加者への配慮

### 2.3 成功指標（KPI）
- 割引設定イベントの参加率向上率
- クーポン利用率
- 新規参加者の獲得数
- 主催者の満足度（アンケート）

#### 4.2.3 決済画面（参加者側）

##### 無料参加時
- TOP画面・イベントカード：赤い「無料参加」ラベル
- イベントページ：価格 ¥0、元価格を取消線で表示
- カート画面：価格 ¥0、元価格を取消線で表示

##### 割引参加時
- TOP画面・イベントカード：：赤い「割引参加」ラベル
- イベントページ：元価格から割引後の金額表示（例：¥1200 → ¥200）
- カート画面：元価格から割引後の金額表示（例：¥1200 → ¥200）

##### クーポン参加時
- TOP画面・イベントカード：：赤い「クーポン」ラベル
- イベントページ：価格は通常表示
- カート画面：クーポン入力欄で割引適用
- 使用済数が発行枠に達すると無効化

## 5. 技術仕様・データ構造設計

### 5.1 Firestoreスキーマ

#### 5.1.1 コレクション構成

```
events/
├── {eventId}/
│   ├── community_bill_settings (フィールド)
│   ├── community_bill_total_amount_with_fee (フィールド)
│   ├── community_bill_off_amount (フィールド)
│   ├── community_bill_fee (フィールド)
│   ├── community_bill_fee_rate (フィールド)
│   └── coupon_usage/ (サブコレクション)
│       ├── {couponUsageId}/
│       │   ├── couponCode
│       │   ├── userId
│       │   ├── usedAt
│       │   └── discountAmount
```

#### 5.1.2 イベントドキュメント拡張
```typescript
// 既存のイベントドキュメントに追加
interface EventDocument {
  // ... 既存フィールド ...
  
  // 割引設定
  community_bill_settings?: {
    type: 'free' | 'discount' | 'coupon';
    off_amount?: number; // 割引金額（discount時のみ）
    coupons?: CouponConfig[]; // クーポン設定（coupon時のみ）
  };
  
  // 請求関連（既存フィールド）
  community_bill_total_amount_with_fee: number; // 請求書払いの合計請求金額
  community_bill_off_amount: number; // コミュニティ請求費用の負担金額
  community_bill_fee: number; // 手数料の金額
  community_bill_fee_rate: number; // 手数料率
}

interface CouponConfig {
  name: string; // クーポン名称
  offAmount: number; // 割引金額
  quantity: number; // 発行数（枠数）
  code: string; // クーポンコード
  redeemed: number; // 使用済数（サーバー管理）
  createdAt: Timestamp; // 作成日時
  updatedAt: Timestamp; // 更新日時
}
```

#### 5.1.3 クーポン使用履歴サブコレクション
```typescript
// サブコレクション: events/{eventId}/coupon_usage
interface CouponUsageDocument {
  id: string; // 自動生成
  couponCode: string; // クーポンコード
  userId: string; // 使用ユーザーID
  usedAt: Timestamp; // 使用日時
  discountAmount: number; // 適用された割引金額
}
```

#### 5.1.4 `community_bill_settings` の構造

##### 無料参加（free）
```json
{
  "type": "free"
}
```

##### 割引参加（discount）
```json
{
  "type": "discount",
  "off_amount": 500
}
```

##### クーポン（coupon）
```json
{
  "type": "coupon",
  "coupons": [
    {
      "name": "学生割",
      "offAmount": 300,
      "quantity": 20,
      "code": "STUDENT300",
      "redeemed": 3
    }
  ]
}
```


### 5.2 Functions設計

#### 5.2.1 Callable Functions（フロントエンドから呼び出し）
- `updateEventDiscountSettings`: イベントの割引設定を更新
  - **引数**: `eventId: string`, `settings: DiscountSettings`
  - **戻り値**: `{ success: boolean, message: string }`
  - **認証**: イベント主催者のみ

- `validateCoupon`: クーポンの有効性を検証
  - **引数**: `eventId: string`, `couponCode: string`
  - **戻り値**: `{ valid: boolean, discountAmount: number, message: string }`
  - **認証**: 認証済みユーザー

- `applyCoupon`: クーポンを適用
  - **引数**: `eventId: string`, `couponCode: string`, `userId: string`
  - **戻り値**: `{ success: boolean, discountAmount: number, message: string }`
  - **認証**: 認証済みユーザー

#### 5.2.2 Trigger Functions（自動実行）
- `onCouponUsage`: クーポン使用時の処理
  - **トリガー**: `events/{eventId}/coupon_usage`サブコレクションの作成
  - **処理内容**: イベントのクーポン使用済数を更新
  - **権限**: システム権限

### 5.3 処理フロー

#### 5.3.1 割引設定の更新
1. 主催者がイベント編集画面で割引設定を選択
2. 選択したタイプに応じて詳細設定を入力
3. バリデーション実行（割引金額、クーポンコードの重複チェック等）
4. Firestoreのイベントドキュメントを更新
5. 成功メッセージを表示

#### 5.3.2 クーポン適用処理
1. 参加者が決済画面でクーポンコードを入力
2. クーポンの有効性を検証（存在チェック、使用済みチェック）
3. 有効な場合、クーポン使用履歴を記録
4. イベントのクーポン使用済数を更新
5. 割引後の価格を表示

#### 5.3.3 バリデーション処理
1. 割引金額が0より大きく、元価格以下であることを確認
2. クーポンコードが一意であることを確認
3. クーポン枠数が正の整数であることを確認
4. 使用済数が発行枠を超えていないことを確認

#### 5.3.4 請求処理
1. 主催者が割引設定を行うと、割引金額が`community_bill_off_amount`に反映
2. 請求書作成時に、割引金額が主催者への請求金額に含まれる
3. クーポン使用時は、使用履歴を`events/{eventId}/coupon_usage`サブコレクションに記録
4. 請求書には、無料参加・割引参加・クーポンで割引いた金額の合計が表示される
