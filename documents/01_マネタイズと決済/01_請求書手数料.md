# 請求書手数料機能

## 1. 概要
### 1.1 機能の目的
イベントでの支払い方法として主催者請求書払い（community_bill）を選択した際に、請求書PDFに手数料を加算する機能を提供する。

### 1.2 主要な機能
- 一律10%の手数料率適用
- 請求書PDFへの手数料明細表示
- 手数料込み合計金額の自動計算
- イベント詳細画面での手数料表示

### 1.3 対象ユーザー
- イベント主催者（請求書PDFでの手数料確認）

## 2. ねらい
### 2.1 ビジネス目標
- 請求書払い利用時の収益確保
- 手数料収入によるプラットフォーム収益化
- シンプルで分かりやすい手数料体系

### 2.2 ユーザー価値
- 透明性のある手数料表示
- 事前の手数料確認による安心感
- 柔軟な支払い方法の選択

### 2.3 成功指標（KPI）
- 請求書払い利用率の向上
- 手数料収入の月次推移

## 3. 前提条件
### 3.1 技術的前提条件
- 既存の請求書PDF生成機能が動作していること

### 3.2 ビジネス的前提条件
- 手数料率は一律10%とする
- 手数料は請求書払い選択時に自動適用される

### 3.3 依存関係
- 請求書PDF生成機能（`functions/legacy/src/eventBillInvoice.js`）
- EventOrderスキーマ（`common/src/schemas/EventOrder.ts`）

## 4. 画面仕様
### 4.1 画面遷移
1. イベント作成画面 → 支払い方法選択 → 請求書払い選択時
2. イベント詳細画面 → 参加申込時 → 手数料表示
3. 請求書PDF → 手数料明細表示

### 4.2 UI要素
- イベント詳細画面：手数料込み金額の表示
- 請求書PDF：手数料明細行の追加

## 5. 技術仕様・データ構造設計
### 5.1 Firestoreスキーマ

#### EventOrderスキーマへの追加
```typescript
// common/src/schemas/EventOrder.ts
const EventOrderDbSchema = z.object({
  // ... 既存フィールド ...
  
  // 請求書手数料関連
  community_bill_fee_amount: z.number().min(0).optional(), // 手数料金額
  community_bill_total_amount_with_fee: z.number().min(0).optional(), // 手数料込み合計
})

export class EventOrder {
  // ... 既存フィールド ...
  
  // 請求書手数料関連
  community_bill_fee_amount: number = 0
  community_bill_total_amount_with_fee: number = 0
  
  // 手数料金額を計算（一律10%）
  calculateBillFee(): number {
    if (this.paymentMethod === 'community_bill') {
      return Math.floor(this.totalPrice * 0.1) // 一律10%
    }
    return 0
  }
  
  // 手数料込み合計を計算
  calculateTotalWithFee(): number {
    return this.totalPrice + this.calculateBillFee()
  }
}
```

### 5.2 Functions設計

#### 5.2.1 請求書PDF生成機能の拡張
既存の請求書PDF生成機能（`functions/legacy/src/eventBillInvoice.js`）を拡張し、手数料分を加算する機能を追加する。

**拡張内容**:
- 請求書払い選択時に一律10%の手数料を適用
- 手数料金額を計算
- 請求書PDFに手数料明細行を追加
- 手数料込み合計金額を表示

**処理フロー**:
1. 既存の請求書PDF生成処理を実行
2. 支払い方法が請求書払い（community_bill）の場合：
   - 手数料金額 = 合計金額 × 0.1（一律10%）
   - 手数料明細行をPDFに追加
   - 手数料込み合計金額を表示
3. その他の支払い方法の場合は既存の処理のまま

**既存コードへの影響**:
- 既存の請求書PDF生成ロジックは維持
- 手数料計算と表示のみを追加
- 既存のAPIインターフェースは変更なし

### 5.3 処理フロー

#### 5.3.1 請求書PDF生成フロー（手数料対応）
1. 請求書PDF生成リクエスト
2. 既存の請求書PDF生成処理を実行
3. 支払い方法が請求書払い（community_bill）の場合：
   - 手数料金額 = 合計金額 × 0.1（一律10%）
   - 手数料明細行をPDFに追加
   - 手数料込み合計金額を表示
4. その他の支払い方法の場合は既存の処理のまま
5. 完成したPDFを返却
