* NG 例の `const event = await getEventInCommunity(...)` は `event` が `undefined` になり得るため、`if (event.is_public)` は TypeScript 的にエラーになり、例としてコピペしづらいです。意図（Transaction 外 read の再利用が NG）を保ったまま、`event?.is_public` など型エラーにならない形にすると誤解が減ります。

})
```
```

**コメント要約**: よくある間違いパターンの NG 例で、undefined になり得る event に対し event.is_public と書いており、ドキュメント例として TypeScript 上も不自然である。

**判断理由**: 指摘は妥当。NG 例の意図は Transaction 外取得の再利用であり、event?.is_public にしてもその意図は伝わる。同ファイルの OK 例は既に event?.is_public を使っているため、NG 例だけ揃えればよい軽微なドキュメント修正。
