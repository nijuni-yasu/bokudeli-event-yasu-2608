**識別子**: RC-1（GitHub id: 3274689034）

**レビュワー**: Copilot

**レビューのコメント（原文）**:

```
[must] event_status（例: applying_reservation → accepting_order）だけが変わった場合、この watch の依存配列に status が入っていないため、以前に onError で PartnerMenu にフォールバック済みだと src が EventMenu 側に戻らず、承認後も PartnerMenu 画像を表示し続ける可能性があります。event.event_status.value（または calculatedEventStatus）も監視して、状態変化時に必ず EventMenu パスへ戻すようにしてください。

This issue also appears on line 37 of the same file.
```

**コメント要約**: watch に event_status が無く、フォールバック後にステータスだけ変わると EventMenu パスに戻らない可能性がある。

**判断結果**: ✅ 対応済み

**判断理由**: 指摘は妥当。watch は event_id, community_id, partner_id, menu_id のみで、onError で PartnerMenu URL に切り替わったあと applying_reservation から accepting_order へ遷移しても src が再計算されない。承認後は EventMenu Storage に画像がある想定だが、表示は PartnerMenu のまま残り得る。event.event_status.value を watch 依存に追加し、変化時に buildEventMenuImageUrl で EventMenu パスへ戻すのがよい。

**対応内容**: watch 依存に event.event_status.value と calculatedEventStatus を追加し、ステータス変化時に EventMenu パスへ src をリセットするよう修正した。
