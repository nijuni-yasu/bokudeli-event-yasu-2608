````
### common/src/constants/imageMimeTypes.ts

🟡 **提案**: `as` キャストを使用しています

```typescript
// 現在
return (ALLOWED_IMAGE_MIME_TYPES as readonly string[]).includes(mimeType)

// 提案: `as` を使わず `some` で代替可能
return ALLOWED_IMAGE_MIME_TYPES.some((m) => m === mimeType)
```

プロジェクトルールとして `as` によるキャストは型推論で解決できる場合は使わない方針です。`some` を使えばキャストなしで同等の動作が得られます。

### base/src/components/ImageInput.vue

🟡 **提案**: `watch` 内で `imageFile.value = null` を設定すると watch が再トリガーされる

```typescript
watch(imageFile, (newFile) => {
  if (newFile == null) { ... return }
  const result = validateImageFile(newFile)
  if (!result.ok) {
    imageFile.value = null  // ← watch が再発火する
    ...
    return
  }
  ...
})
```

`imageFile.value = null` の設定によって watch が再発火し、`newFile == null` の早期リターンで副作用なく終了するため動作上の問題はありません。ただし、この「watch が自分自身を間接的に再発火させる」設計は把握しにくいです。

`{ once: false }` の挙動や Vue の watch flush タイミングによっては予期しない挙動が発生しないか確認してください。代替案として `imageFile.value = null` の代わりにローカル変数で管理し、`emit` のみで完結させる方法も検討できます。
````

````
**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  画像アップロード失敗時のリロードを防ぐ**

`image` はアップロード前に保持した値なので、`uploadUserImage` が失敗しても `image != undefined` は真のままです。そのためこの新規リロード処理が必ず実行され、失敗時でも 1 秒後に画面再読込されて再試行しづらくなります（新規ユーザー経路でも同じ条件で強制遷移します）。リロード/遷移はアップロード成功時に限定するフラグで判定すべきです。

Useful? React with 👍 / 👎.
````

**コメント要約**: profileSubmit のリロード判定 `if (image != undefined)` は、`uploadUserImage` が失敗（catch 経路）でも真のままになるため、失敗時にもリロード/完全遷移が走る。アップロード成功時のみリロードするフラグ判定に変更すべき。

**判断結果**: 🚨 修正推奨

**判断理由**: 指摘どおり、現在の実装は `image = userImage.value` でアップロード前にローカル変数に保持しており、try/catch で失敗が握りつぶされても `image != undefined` の判定はそのままに残る。アップロード失敗 → アラート表示 → 1 秒後に意図しないリロードが走り、再試行のチャンスを奪う実害がある。

修正案: アップロード成功フラグを別途持ち、リロード判定をそれに切り替える。

```ts
let uploadSucceeded = false
if (image != undefined) {
  try {
    await currentUserStore.uploadUserImage(image)
    uploadSucceeded = true
    userImage.value = undefined
    // ...
  } catch (err) {
    console.error(err)
    window.alert($t('profile.fail_image_upload'))
  }
}

// ...

if (uploadSucceeded) {
  window.setTimeout(() => {
    window.location.reload()
  }, 1000)
}
```

isNewUser 経路でも同じく `uploadSucceeded` で分岐する。
