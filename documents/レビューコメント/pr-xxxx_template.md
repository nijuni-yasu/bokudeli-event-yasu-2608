# PR #[PR番号] レビューコメント評価

このファイルは **記録フォーマットのテンプレート**です。実際の記録では `pr-[番号].md` にコピーし、角括弧や（記入）部分を実値で置き換えてください。

**記載方針**: レビュワーのコメントは **原文**のまま（GitHub `body` またはエージェント指摘文）。**該当コード**は `diff_hunk` または `git diff origin/development...HEAD`（長い場合は末尾優先・最大約80行・改変禁止）。

**判断結果（4区分・共通）**: 🚨 必須修正 / 🟡 修正提案 / 👌 修正不要 / ✅ 対応済み のみ。**❌ 未対応は使わない**。未着手はチェックリストの `[ ]` と 🚨 / 🟡 で表す。`/review-comments-evaluate` と `/shokujii-code-review` で同一。

**スキル**: 外部コメント評価 → `/review-comments-evaluate`。能動レビュー → `/shokujii-code-review`。同一 PR で RC 番号は通し。
