### 👌 修正不要（確認済み）

**`extractPlainTextFromVNode.ts` — `children.default?.()` の引数なし呼び出し**
`v-linkify` の現在の使用箇所（`v-card-text`・`<p>` 等）はシンプルなテキスト表示のみで、スコープドスロット（context 引数を受け取るスロット）はありません。引数なし呼び出しで `undefined` が返る場合も `collectTextFromChild` の `child == null` ガードで空文字扱いになるため、問題なし。

**`linkifiedSegments.ts` — `split(' ')` によるスペース区切り**
改行（`\n`）を含むメッセージはスペースで分割されませんが、URL 正規表現の `\b` が改行後の URL 先頭に対してもマッチするため実害なし。旧コード (`el.textContent?.split(' ')`) と同じ挙動を踏襲しており、意図的。

**`renderLinkifiedContent.ts` — `el.replaceChildren()`**
Chrome 86+ / Firefox 78+ / Safari 14+ 以降で対応。プロジェクトの対象ブラウザ範囲内であれば問題なし。

**XSS 修正全体**
`innerHTML` を廃止し `createTextNode` / `createElement('a')` の DOM API へ移行した実装は適切。`rel="noopener noreferrer"` の付与も正しい。

**`truncateLastMessagePreview` の UTF-16 切り詰めロジック**
