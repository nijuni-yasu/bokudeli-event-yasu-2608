# ブランチ [ブランチ名] レビュー記録

このファイルは **記録フォーマットのテンプレート**です。実際の記録では `review-<ブランチの/を-に置換>.md`（例: ブランチ `fix/2500` → `review-fix-2500.md`）にコピーし、角括弧や（記入）部分を実値で置き換えてください。パス解決の正本は `.agents/skills/review-comments-evaluate/references/review-doc-path.md`。

**記載方針**: レビュワーのコメントは **原文**のまま（GitHub `body` またはエージェント指摘文）。**該当コード**は `diff_hunk` または `git diff origin/development...HEAD`（長い場合は末尾優先・最大約80行・改変禁止）。

**判断結果（共通区分）**: 🚨 必須修正 / 🟡 修正提案 / 👌 修正不要 / ✅ 対応済み / 📤 #NNNN 別Issue化。**❌ 未対応は使わない**。未着手はサマリ表の **対応** 列 `[ ]` と 🚨 / 🟡 で表す。別 Issue へ切り出したら `/git-create-issue` で Issue を作成し、判断列を **📤 #NNNN 別Issue化**、対応列を `[x]`、PRスコープを **📤 スコープ外** に更新する。RC 対応の実装完了時も AGENTS.md の「レビューコメント対応記録」に従い当該 `review-<slug>.md` を同一作業内で更新する。`/review-comments-evaluate` と `/shokujii-code-review` で同一。

**変更種別・PRスコープ・ラベル・想定工数**: `/review-comments-evaluate` の各節と同一語彙（スキル内「変更種別」「PRスコープ」「ラベル」「想定工数」を参照）。**ラベルは複数可**（`💰 金銭, 🔒 セキュリティ`）。**推測ラベルは使わない**（該当なしは `—`）。

**スキル**: 外部コメント評価 → `/review-comments-evaluate`。能動レビュー → `/shokujii-code-review`。同一ブランチ（= 同一ファイル）で RC 番号は通し。
