**[must] `.claude/settings.json` — `deny` に保護ブランチへの直 push が明示されていない**

`allow` に `"Bash(git push *)"` を追加しましたが、`deny` リストには `--force` 系のみ記載されており、`git push origin main` / `git push origin production` / `git push origin development` の通常 push が明示的に拒否されていません。現状では `protect-git-release.sh` Hook のみが唯一の防壁です。

AGENTS.md §Git ルール（エージェント向け Git 操作の禁止）では「development / main / production への直 push 禁止」と明記されており、Hook 失敗時のフォールバックとして `deny` に以下を追加することを推奨します。

```jsonc
// deny に追加
"Bash(git push origin main*)",
"Bash(git push origin production*)",
"Bash(git push origin development*)"
```

**[imo] `.claude/settings.json` — `Bash(cat *)` allow で `.secret` が無許可読み取り可能**
