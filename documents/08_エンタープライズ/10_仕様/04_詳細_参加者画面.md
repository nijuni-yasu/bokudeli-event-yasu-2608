# 1. グローバルメニュー

参加者画面の横ナビ / モバイル縦ナビ（`enterprise/src/navigation/index.ts`）は次のとおり。

| 表示名 | 遷移先 | 表示条件 | 備考 |
|:--|:--|:--|:--|
| イベント参加 | `/` | 常時 | |
| コミュニティ | コミュニティ一覧 | 常時 | |
| イベント開催 | `/manage` | 常時 | 未ログイン時は既存ルーターガードで `/login` |

# 2. トップページ（`/`）

## 2.1 概要

`enterprise/src/pages/index.vue` は同一 `enterprise_id` 内の**公開イベント**（`is_public == true`、`event_status.value == 'accepting_order'`）を3セクションで表示する。

## 2.2 クエリ（MVP・#2138）

共通条件: `where('enterprise_id', '==', myEnterpriseId)`、`where('is_public', '==', true)`、`where('event_status.value', '==', 'accepting_order')`。

3クエリすべてに **`where('event_num_members', '>=', 0)`** を付与する（注文0件のイベントも表示。Firestore の inequality / orderBy 制約を満たすため下限 0）。PF 版トップ（`user/src/pages/index.vue`）も #2288 以降同条件（テナントは `enterprise_id == null`）。

| セクション | 追加条件 | 並び順 | 表示件数 |
|:--|:--|:--|:--|
| 人気のイベント | `event_deadline_datetime > now` | `orderBy('event_num_members', 'desc')` | 先頭3件（`popularEvents` で slice） |
| 開催予定のイベント | `event_end_datetime > now` | `orderBy('event_start_datetime', 'asc')` | ページング（`IncrementalLoader`） |
| 終了したイベント | `event_end_datetime <= now` | `orderBy('event_start_datetime', 'desc')` | 開催予定の読み込み完了後にページング |

### 仕様上の理由

社内告知・予約受付開始直後など、**まだ注文がない公開イベント**もトップから見せる（[01_仕様概要](./01_仕様概要.md)「人事部が毎日開催」と整合）。

> Phase 2（G-6）以降は `publish_scope` ベースのクエリへ移行する（[04_詳細_イベント管理](./04_詳細_イベント管理.md) §4.1）。MVP のトップ実装正本は本 §2.2。

# 3. バナー表示（#2139）

## 3.1 MVP: PF 共通バナー非表示

エンプラ参加者画面では、一般版と共有の Firestore `assets/{documentId}` バナーを**表示しない**（UI 側のみ。Firestore データは変更しない）。

| 画面 | PF 版 | エンプラ版（MVP） |
|:--|:--|:--|
| トップ | `top_banners` / `center_banners`（`useBannersStore` + `<Banners>`） | **非表示** |
| イベント詳細 | `event_banners` | **非表示** |

## 3.2 Phase 2: 企業専用バナー（G-4）

企業専用 `enterprises/{id}.top_banner` や `feature_flags` による ON/OFF は **Phase 2（WS-G G-4）** で導入する（[01_MVP全体計画](../00_計画/01_MVP全体計画.md)）。MVP ではバナー枠自体を出さない。

# 4. PF 版との差分一覧

| 論点 | PF 版（`user`） | エンプラ版（`enterprise`） |
|:--|:--|:--|
| グローバルメニュー | 5項目（マガジン・X・about 含む） | 3〜4項目（§1.1）。マーケ導線はフッター |
| ヘッダー admin 導線 | — | 参加者画面右上の独立ボタンなし（§1.3） |
| トップ `event_num_members` | **`>= 0`**（§2.2 / #2288） | **`>= 0`**（§2.2） |
| トップ / イベント詳細バナー | `assets/*` 表示 | **非表示**（§3.1） |
| トップクエリのテナント | `enterprise_id == null`（PF 露出フィルタ） | `enterprise_id == myEnterpriseId` |
