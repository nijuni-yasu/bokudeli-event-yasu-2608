# オンボーディング 詳細仕様

本ドキュメントは `01_仕様概要`、`02_全体構成・アーキテクチャ`、`04_認証・アカウント管理`、`04_監査ログ` の決定事項に基づき、企業オンボーディング（初代 admin ブートストラップ）の機能仕様を詳細に定義する。

---

# 1. 概要

## 1.1 対象機能

| 機能 | 概要 |
|:--|:--|
| 企業オンボーディング | 運営が `createEnterprise` で `/enterprises/{id}` と初代 admin を一括作成 |

## 1.2 決定事項サマリ

| # | 論点 | 決定 |
|:--|:--|:--|
| O-1 | 初代 admin の作成 | 運営専用 Callable `createEnterprise` で同時作成（CSV 一括作成の鶏卵問題を解消） |
| O-2 | 企業作成 UI | MVP は運営 / スクリプト運用。管理画面 UI は Phase 2 |
| O-3 | テーマカラー / allowed_email_domains | MVP では運営が `createEnterprise` で設定。管理者による編集は Phase 2（`04_全社管理者画面` 補足 A/B 参照） |

---

# 2. 背景

エンタープライズ版の利用開始には以下が必要だが、従来は「運営が Firestore に手動設定」止まりで、**初代 admin が存在しないと CSV 一括作成もできない**鶏卵問題があった。

# 3. Functions: createEnterprise

運営（サポートアカウント）専用の Callable Function。企業ドキュメントと初代 admin を一括作成する。

## 3.1 実行権限

- `isSupport()`（サポートアカウント）のみ実行可能
- 一般ユーザー・企業 admin からは呼び出せない

## 3.2 リクエスト

```typescript
interface CreateEnterpriseRequest {
  enterprise_id: string              // ドキュメント ID（例: "company-a"）
  company_name: string
  subdomain: string                  // 例: "company-a" → company-a.shokujii.com
  custom_domain?: string             // 任意
  allowed_email_domains: string[]    // 例: ["company-a.com", "company-a.co.jp"]
  theme_color: string                // 例: "#1976D2"
  enterprise_subsidy_settings: {      // 初期割引設定
    type: 'fixed' | 'percentage'
    value: number
    monthly_limit_per_user: number
  }
  initial_admin: {                   // 初代 admin（1名必須）
    email: string
    display_name: string
    department?: string
  }
}
```

## 3.3 処理フロー

```
1. isSupport() チェック
2. enterprise_id / subdomain の重複チェック
3. /enterprises/{enterpriseId} ドキュメントを作成
   - company_name, subdomain, custom_domain, allowed_email_domains
   - theme_color, enterprise_subsidy_settings, is_active: true
4. initial_admin を createEnterpriseMembers ロジックで作成
   - Firebase Auth ユーザー作成
   - custom claims: { enterprise_id, enterprise_role: 'admin', user_type: 'enterprise' }
   - /enterprises/{id}/members/{userId}, /users/{userId}, /users_personal_information/{userId}
5. 監査ログ記録（action: 'enterprise_create'）
6. レスポンス返却
```

## 3.4 レスポンス

```typescript
interface CreateEnterpriseResponse {
  enterprise_id: string
  initial_admin_user_id: string
}
```
