**凡例**

- **公開** … `is_public == true`（同社イベント一覧に表示）
- **URL限定** … `is_public == false`（URLを知る者のみ。部署定例・招待制向け）
- **デモ優先度 A** … 最小セット（§デモセット）に含める
- ゲスト **`free`** … 企業負担（就活生・卒業生向けデモ）。`04_ゲスト参加` 参照
- ゲスト **`self_pay`** … 外部講師等が全額自己負担（Stripe テスト決済デモ用）

## デモシナリオ

### 15分デモ（最小セット）

```
1. [全社管理者] admin@ でログイン
   → /admin ダッシュボード（アカウント数・コミュニティ数・当月利用状況）

2. [一般社員] member@ でログイン
   → トップの公開イベント一覧
   → 「出社推奨日ランチ」詳細 → 注文（500円引き・自己負担額の表示）

3. [部署リーダー] dev-lead@ でログイン
   → /manage/community/dev-lunch
   → 「開発部定例ランチ」（URL限定）の manage 画面

4. [ゲスト] 別ブラウザ / シークレット
   → リファラル採用交流会の URL を開く（未認証で詳細閲覧）
   → ゲストログイン → 注文（企業負担・Stripe スキップ）

5. [任意] club@ でボドゲ同好会のコミュニティページ
   → 「社員が自分でサークルを作れる」補足
```

### 30分デモ（フルセット追加）

最小セットに加え、以下を順に触れる。

- 人事 `hr@` … 月例ウェルカム・シャッフルランチの作成フロー（manage）
- 経営 `exec@` … 社長ランチ（URL限定・少人数）
- AI勉強会 … ゲスト `self_pay` で Stripe テスト決済
- `/admin/members` … メンバー一覧・部署フィルタ
- `/admin/communities/import` … CSV 一括作成 UI（実行は省略可）

## データ投入手順（概要）

1. **企業作成** … `createEnterprise`（`09_デプロイ手順` §11）。§デモ企業プロフィールの値を使用
2. **メンバー投入** … `/admin/members/import` で §メンバー CSV
3. **コミュニティ投入** … `/admin/communities/import` で §コミュニティ CSV
4. **イベント作成** … 各 manager で `/manage` から手動作成（最小セット5件から開始）
5. **ゲスト検証** … PF版ユーザー `guest@example.com` でリファラル採用交流会 URL から参加

> イベントの店舗・メニューは sandbox 上で注文可能な partner / メニューが存在する必要がある。メニュー未連携の場合はイベント詳細・manage 画面のみのデモとする。
