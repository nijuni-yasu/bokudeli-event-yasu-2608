# エンタープライズ版 v0.1 MVP 未実装の洗い出し

## 目的

エンプラ版 v0.1 について、現状コードを確認した上で「MVP リリース予定だった内容」かつ「まだ実装できていない内容」を洗い出す。

`enterprise` パッケージ・`common/src/schemas|apis`・`functions/default/src`・`firestore.rules`・`tests/firestore-rules` を、実装計画（`08_エンタープライズ_実装計画.md`）の Phase 1〜7 および `01_エンタープライズ_仕様概要.md` の「MVP（Phase 1）」スコープと突き合わせた。

## MVP 予定 かつ 未実装の項目

### 1. メール配信制御（Phase 5）— 未実装

- MVP 必須（`01_仕様概要` の「メール配信機能の修正」、`08_実装計画` Phase 5）。
- 根拠: `functions/default/src/*Mail.ts`（`eventInformationMail` / `remindUnorderedMail` / `orderRemindMail` / `popularEventMail` / `eventConclusionMail` ほか）に **`enterprise_id` / `user_type` による送信スキップ処理が一切存在しない**。
- 影響: エンプラ版イベント/ユーザーに、PF 版の不要メール（締切リマインダー・終了アンケート・新着通知・イベント情報メール等）が送られてしまう。

### 2. ダッシュボード（Phase 6）— 未実装

- MVP 必須（`01_仕様概要` の「ダッシュボード」、月別／メンバー別の利用回数・人数・金額 + CSV）。
- 根拠: `enterprise/src/pages/admin/index.vue` は `/admin/settings` へ **リダイレクトするだけ**。集計 Callable（`getEnterpriseDashboard` 等）も `common/src/apis/enterprise.ts`・`functions` に **存在しない**。CSV ダウンロード機能もなし。

### 3. 監査ログ閲覧 UI（Phase 6）— 未実装

- MVP 必須（`01_仕様概要` の「監査ログ閲覧機能」）。
- 根拠: 書き込み（`writeAuditLog`）は各 Callable に実装済みだが、**閲覧 UI（`/admin/audit-logs`）と取得 Callable（`getEnterpriseAuditLogs`）が存在しない**。管理者ナビ（`enterprise/src/navigation/admin.ts`）にも監査ログ項目なし（計画通り Phase 6 まで非表示）。

### 4. 課金スナップショット（Phase 6 / 6-3）— 未実装

- MVP-C（手動請求）の根拠データ。`captureEnterpriseBillingSnapshots`（毎月 1 日 00:05 JST の Scheduled Function、`billing_snapshots` 永続化）。
- 根拠: 該当 Function がコードに **存在しない**（`onboarding.ts` の `billing_settings` 初期化のみ）。

### 5. マイページ・友人の認可レイヤ（Phase 7）— 未実装

- MVP 範囲（`08_実装計画` の MVP スコープに「マイページ/友人の認可（内訳 UI 除く）」を明記）。
- 根拠: 計画上の `assertEnterpriseProfileAccess` がコードに無く（docs のみ）、`userProfile.ts` / `userFriends.ts` に **`enterprise_id` フィルタが一切ない**。エンプラ側 `mypage.vue` / `u/[userId].vue` は PF 版 Callable をそのまま呼ぶため、**テナント分離が効かない懸念**がある。

## 判断が必要な項目（ドキュメント間で扱いが矛盾）

### ゲスト参加機能

- `01_仕様概要` では「MVP から対応」と記載。一方 **`08_実装計画` では明確に「MVP に含まない（将来実装）」へ再分類**されている。
- 現状: スキーマ（`Event.allow_guest` / `guest_payment` / `EventMember.is_guest`）は **未実装**。
- → 「MVP 予定だった内容」とみなすかは、最新方針である `08`（将来実装）に従うか、`01`（MVP）に従うかで変わる。**要判断。**

## まとめ（未実装リスト）

最新の実装計画（`08`）を基準にすると、**MVP 予定かつ未実装**は次の 5 点。

1. メール配信制御（Phase 5）
2. ダッシュボード + CSV（Phase 6）
3. 監査ログ閲覧 UI（Phase 6、書き込みは実装済み）
4. 課金スナップショット Scheduled Function（Phase 6-3）
5. マイページ・友人の認可レイヤ（Phase 7）

加えて、**ゲスト参加**は仕様書間で MVP/将来の扱いが矛盾しているため、方針確認が必要。
