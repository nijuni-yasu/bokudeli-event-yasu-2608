# メール配信 詳細仕様

本ドキュメントは `01_仕様概要` および `02_全体構成・アーキテクチャ` の決定事項に基づき、エンタープライズ版におけるメール配信制御の仕様を詳細に定義する。


# 1. 概要

エンタープライズ版では、プラットフォーム版（PF版）と同一の Firebase プロジェクト・SendGrid を利用する。ユーザー種別（`user_type`）およびイベント/コミュニティのテナント（`enterprise_id`）に応じて、一部のメールを PF版ユーザーのみに送信し、エンタープライズ版ユーザーには送信しない。

## 1.1 目的

- エンタープライズ版ユーザーに不要なマーケティング・プロモーション系メールを送信しない
- イベント・注文・認証に関連する必須メールは PF版・エンタープライズ版の両方に送信する
- 実装の工数を最小限に抑える

## 1.2 決定事項サマリ

| # | 論点 | 決定 |
|:--|:--|:--|
| M-1 | 配信制御の対象 | ユーザー向けメール（店舗・運営向けは対象外） |
| M-2 | 判定方式 | イベント/コミュニティの `enterprise_id` による早期リターン |
| M-3 | 実装方針 | 共通ヘルパー + 各送信処理の冒頭で1行追加 |

# 3. PF only / PF + Enterprise の判定

## 3.1 判定基準

| 種別 | 説明 | 判定方法 |
|:--|:--|:--|
| **PF only** | プラットフォーム版ユーザーのみに送信。エンタープライズ版では送信しない | イベント/コミュニティの `enterprise_id` が存在する場合は送信スキップ |
| **PF + Enterprise** | 両方に送信。イベント・注文・認証に関連する必須メール | `enterprise_id` の有無に関係なく送信 |

# 4. 実装方式

## 4.1 方針：共通ヘルパー + 早期リターン

工数を最小限に抑えるため、以下の方式を採用する。

1. **共通ヘルパー関数**を1つ作成
2. **PF only メール**の各送信処理の冒頭で、ヘルパーによる早期リターンを追加（1行）

## 4.2 共通ヘルパー

```typescript
// functions/default/src/utils/enterprise.ts（新規）または utils/mail.ts に追加

/**
 * エンタープライズコンテキストのイベントかどうか
 * PF only メールはエンプライベントでは送信しない
 */
export function isEnterpriseEvent(event: { enterprise_id?: string | null }): boolean {
  return !!event.enterprise_id
}
```

### 前提条件

- `enterprise_id` はイベント（Event）または親コミュニティ（Community）に持たせる（エンプラ導入時のスキーマ設計に従う）
- `enterprise_id` が `null` / `undefined` の場合は PF版として扱い、送信する（後方互換）

### enterprise_id の配置（実装方式）

| 方式 | 内容 | ヘルパー |
|:--|:--|:--|
| **A. Event に denormalize** | イベント作成時に `community.enterprise_id` を Event にコピー。`isEnterpriseEvent(event)` でそのまま参照 | 同期関数のまま |
| **B. Community から取得** | Event に `enterprise_id` を持たず、`getCommunity(event.community_id)` で取得 | 非同期ヘルパー `isEnterpriseEventAsync(event)` が必要 |

スキーマ設計が固まったら、採用方式を確定する。方式 A を推奨（既存の同期ヘルパーで対応可能）。

const event = await getFirestore().runTransaction(async (transaction) => {
  const transactionEvent = await getEvent(eventId, transaction)
  if (transactionEvent == null || !transactionEvent.is_public || transactionEvent.sent_new_event_mail_at) {

  return transactionEvent
