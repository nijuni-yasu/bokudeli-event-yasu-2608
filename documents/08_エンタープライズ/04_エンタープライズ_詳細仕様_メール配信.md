# メール配信 詳細仕様

本ドキュメントは `01_仕様概要` および `02_全体構成・アーキテクチャ` の決定事項に基づき、エンタープライズ版におけるメール配信制御の仕様を詳細に定義する。

## 前提とする仕様書

本ドキュメントは EventMemberOrder 設計（`05_EventOrder→EventMemberOrder.md`）を前提とする。注文関連のメールトリガーは旧 `onOrderChanged`（`orders` コレクションの Firestore トリガー）から、新設計では **`onMemberOrderChanged`**（`member_orders` の Firestore トリガー）に変わる。1 注文セッション = 複数の `member_orders` ドキュメントになるため、注文完了系メールはセッション単位で **1 回だけ送信** する重複防止が必要（02 論点 8.3）。


# 1. 概要

エンタープライズ版では、プラットフォーム版（PF版）と同一の Firebase プロジェクト・SendGrid を利用する。ユーザー種別（`user_type`）およびイベント/コミュニティのテナント（`enterprise_id`）に応じて、一部のメールを PF版ユーザーのみに送信し、エンタープライズ版ユーザーには送信しない。

## 1.1 目的

- エンタープライズ版ユーザーに不要なマーケティング・プロモーション系メールを送信しない
- イベント・注文・認証に関連する必須メールは PF版・エンタープライズ版の両方に送信する
- 実装の工数を最小限に抑える

## 1.2 決定事項サマリ

| # | 論点 | 決定 |
|:--|:--|:--|
| M-1 | 配信制御の対象 | ユーザー向けメール（店舗・運営向けは対象外） |
| M-2 | 判定方式 | イベント/コミュニティの `enterprise_id` による早期リターン |
| M-3 | 実装方針 | 共通ヘルパー + 各送信処理の冒頭で1行追加 |
| M-4 | `enterprise_id` の配置 | **方式A（Event へ denormalize）確定**（`02` §3.4 参照） |

# 3. PF only / PF + Enterprise の判定

## 3.1 判定基準

| 種別 | 説明 | 判定方法 |
|:--|:--|:--|
| **PF only** | プラットフォーム版ユーザーのみに送信。エンタープライズ版では送信しない | イベント/コミュニティの `enterprise_id` が存在する場合は送信スキップ |
| **PF + Enterprise** | 両方に送信。イベント・注文・認証に関連する必須メール | `enterprise_id` の有無に関係なく送信 |

# 4. 実装方式

## 4.1 方針：共通ヘルパー + 早期リターン

工数を最小限に抑えるため、以下の方式を採用する。

1. **共通ヘルパー関数**を1つ作成
2. **PF only メール**の各送信処理の冒頭で、ヘルパーによる早期リターンを追加（1行）

## 4.2 共通ヘルパー

```typescript
// functions/default/src/utils/enterprise.ts（新規）または utils/mail.ts に追加

/**
 * エンタープライズコンテキストのイベントかどうか
 * PF only メールはエンプライベントでは送信しない
 */
export function isEnterpriseEvent(event: { enterprise_id?: string | null }): boolean {
  return !!event.enterprise_id
}
```

### 前提条件

- `enterprise_id` はイベント（Event）または親コミュニティ（Community）に持たせる（エンプラ導入時のスキーマ設計に従う）
- `enterprise_id` が `null` / `undefined` の場合は PF版として扱い、送信する（後方互換）

### enterprise_id の配置（方式A 確定）

**方式A（Event へ denormalize）を採用する。** イベント作成時に `community.enterprise_id` を Event にコピーし、`isEnterpriseEvent(event)` を同期関数のまま使用する。

| 方式 | 内容 | ヘルパー | 採用 |
|:--|:--|:--|:--|
| **A. Event に denormalize** | イベント作成時に `community.enterprise_id` を Event にコピー | 同期 `isEnterpriseEvent(event)` | **確定** |
| B. Community から取得 | Event に `enterprise_id` を持たず都度取得 | 非同期 `isEnterpriseEventAsync(event)` | 不採用 |

### 不変条件

Community が `enterprise_id` を持つ場合、配下の **Event / members / member_orders / stripes** にも必ず同一の `enterprise_id` を denormalize する。詳細は `02_全体構成 3.4` を参照。

| 経路 | 処理 |
|:--|:--|
| イベント作成 / 複製 | `community.enterprise_id` を Event にコピー |
| `addToCart` | Event の `enterprise_id` を members / member_orders にコピー |
| `stripeWebhook` | Event の `enterprise_id` を stripes にコピー |
