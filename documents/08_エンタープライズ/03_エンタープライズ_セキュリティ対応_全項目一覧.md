# セキュリティ対応 全項目一覧

エンタープライズ版に関連するセキュリティ・コンプライアンス項目の全体像とステータスを管理する。
各項目の技術詳細は「参照先」のドキュメントを参照。

**ステータス定義:**

| ステータス | 意味 |
|:--|:--|
| **MVP対応済み** | MVP の設計・実装に組み込み済み |
| **検討済み** | 技術調査・方針決定が完了。実装は Phase 2 以降 |
| **ドラフト済み** | ドラフトは作成したが最終化していない（法務チェック・経営判断待ち等） |
| **回答準備済み** | セキュリティチェックシートへの回答が準備できている |
| **要検討** | 未着手。技術調査または方針決定が必要 |

# ステータスサマリ

| ステータス | 件数 | 項目 |
|:--|:--|:--|
| **MVP対応済み** | 4件 | セッション管理、監査ログ、デフォルト暗号化、Storage パス設計 |
| **検討済み** | 7件 | SSO、CMEK、フィールドレベル暗号化、IP制限（API層）、IP制限（完全）、データ削除対応、第三者認証方針、物理分離 |
| **ドラフト済み** | 4件 | プライバシーポリシー、インシデント対応、セキュリティポリシー、SLA、障害時連絡体制 |
| **回答準備済み** | 5件 | サブプロセッサー、リージョン、DDoS、TLS、XSS/CSRF、バックアップ |
| **要検討** | 7件 | MFA、アカウントロックアウト、APIレート制限、データ保持ポリシー、データエクスポート、脆弱性診断、CSP、ファイルアップロード制限、脆弱性パッチ |

**次に着手すべき項目:**

| 優先度 | 項目 | 理由 |
|:--|:--|:--|
| 高 | ドラフト済み項目の最終化 | 担当者決定・経営判断・法務チェックのみで完了。技術作業なし |
| 中 | D5 データ保持ポリシー | プライバシーポリシーの最終化に必要（保管期間の決定） |
| 中 | F6 脆弱性パッチ適用体制 | npm audit の頻度を決めるだけ。チェックシートで聞かれる |
| 低 | A4 MFA / A5 ロックアウト | Phase 2 の実装。SSO 対応後に検討 |
