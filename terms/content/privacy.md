# shokujii プライバシーポリシー

ニジュウニ株式会社（以下「当社」といいます。）は「shokujii」（以下「本サービス」といいます。）を運営するに当たり、プライバシー保護に最大限の注意を払っています。本サービスの利用に関するプライバシーポリシーは、以下のとおりです。

**第１条　適用範囲について**

プライバシーポリシーは、本サービスを利用する法人、団体、組合、または個人のお客様（以下「お客様」といいます。）が本サービスのすべてのサービスを利用するときに適用されます。したがって、本サービスがお客様から取得した個人情報は、プライバシーポリシーに従って取り扱われます。

**第２条　お客様から取得する個人情報**

お客様が本サービスをご利用いただくに当たり、当社は以下の情報を取得します。

・氏名（ニックネームやペンネーム含む）

・メールアドレス

・SNSアカウント

・チャット機能の利用に伴い取得する情報（以下「チャット情報」といいます。）

　・テキストメッセージの本文

　・画像メッセージに添付する画像データ、ファイル形式、元ファイル名、ファイルサイズ、画像の幅および高さ

　・メッセージの送受信日時、送信者を識別する情報

　・チャットルームへの参加情報、ルームの状態、参加・離脱に伴うシステム通知の内容

　・未読件数、最終既読日時、ルーム一覧表示用の最新メッセージ要約

　・送信取り消しの実行日時、取り消し時点の表示名等、取り消しに伴い残る情報

　・お客様がメッセージ本文または画像に任意で含める第三者の個人情報

**第３条　個人情報の利用目的**

当社は、お客様から取得した情報を、以下の目的のために利用します。また、以下の利用目的を変更前の利用目的と関連性を有すると合理的に認められる範囲内において変更することがあり、変更した場合には、お客様に対し、通知又は当社サイト上での掲示その他分かりやすい方法により公表します。

・当社のサービスを提供するため

・当社のサービスの改善及び新サービス、新機能の開発のため

・お客様の本人確認や認証を行うため

・お客様にご自身の登録情報の閲覧や変更、削除、ご利用状況の閲覧を行っていただくため

・システムの維持、不具合対応のため

・サービスの解約や解約後の事後管理を行うため

・商品購入時や有料サービス利用時等におけるご請求処理のため

・市場分析、マーケティングのため

・お客様の属性や趣向等を分析し、当該属性や趣向等に最適化されたコンテンツ、広告等の表示、電子メール、SMS、当社が運営するウェブサイト上のチャットウィジェット、ブラウザ上での通知等の方法で、当社からの案内・広告等のメッセージ送信を行うため

・当社のサービスにおけるお客様の行動履歴を分析し、当社のサービスの維持改善に役立てるため

・当社のサービスに関連して、個人又は特定の利用者を識別できない形式に加工した統計データを作成するため

・アンケートの実施のため

・当社の規約や法令に違反する行為に対応するため

・当社のサービスに関する規約等の変更などを通知するため

・当社のサービスに関するご案内をするため

・提携する事業者・サービスのご案内をお送りするため

・お客様に対する情報（ブログ、メールマガジン等）の発信

・お客様からのお問い合わせに対応するため

・サービス内またはウェブサイト上で、ご利用の体験談や感想を紹介するため

・当社の利用規約に違反したユーザーや、不正・不当な目的でサービスを利用しようとするユーザーの特定をし、ご利用をお断りするため
・当社のユーザーにご自身の登録情報の閲覧や変更、削除、ご利用状況の閲覧を行っていただくため
・当社の有料サービスにおいて、ユーザーに利用料金を請求するため

・その他、上記利用目的に付随する目的のため

・イベント参加者同士の連絡・交流のため

・チャット機能における未読管理、ルーム一覧表示、システム通知の表示のため

・チャット機能における不正利用、迷惑行為、規約違反への対応のため

**第４条　個人情報の安全管理**

当社は、個人情報の紛失、破壊、改ざん及び漏洩などのリスクに対して、個人情報の安全管理が図られるよう、必要かつ適切な措置を講じます。また、当社は、個人情報の取扱いの全部又は一部を委託する場合は、委託先において個人情報の安全管理が図られるよう、必要かつ適切な監督を行います。

**第５条　第三者提供**

当社は、次に掲げる場合を除いて、お客様の同意を得ることなく個人データを第三者に提供しません。

1. 法令に基づく場合
2. 人の生命、身体又は財産の保護のために必要がある場合であって、本人の同意を得ることが困難であると判断した場合
3. 公衆衛生の向上又は児童の健全な育成の推進のために特に必要がある場合であって、本人の同意を得ることが困難であると判断した場合
4. 国の機関若しくは地方公共団体又はその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、本人の同意を得ることによって当該事務の遂行に支障を及ぼす恐れがあると判断した場合
5. 利用目的達成に必要な範囲内において個人データの取扱の全部又は一部を委託するに伴い個人データを提供する場合
6. 合併その他の事由による事業の承継に伴って個人データが提供される場合
7. 特定の者との間で共同して利用する個人データを当該特定の者に提供する場合であって、その旨並びに共同して利用する個人データの項目、共同して利用する者の範囲、利用する者の利用目的及び当該個人データの管理について責任を有する者の氏名又は名称について、あらかじめ、本人に通知、又は本人が容易に知り得る状態に置いているとき

8. 予め次の事項を告知あるいは公表し、かつ当社が個人情報保護委員会に届出をしたとき
   ・利用目的に第三者への提供を含むこと
   ・第三者に提供されるデータの項目
   ・第三者への提供の手段または方法
   ・本人の求めに応じて個人情報の第三者への提供を停止すること
   ・本人の求めを受け付ける方法

9. 前項の定めにかかわらず、次に掲げる場合には、当該情報の提供先は第三者に該当しないものとします。
   ・当社が利用目的の達成に必要な範囲内において、個人情報の取扱いの全部または一部を委託する場合
   ・合併その他の事由による事業の承継に伴って個人情報が提供される場合
   ・個人情報を特定の者との間で共同して利用する場合であって、その旨並びに共同して利用される個人情報の項目、共同して利用する者の範囲、利用する者の利用目的および当該個人情報の管理について責任を有する者の氏名または名称について、あらかじめ本人に通知し、または本人が容易に知り得る状態に置いた場合

**第５条の２　クラウドサービスへの委託**

当社は、本サービスの提供にあたり、Google LLC が提供する Firebase Authentication、Cloud Firestore、Cloud Functions、Cloud Storage その他の Google Cloud サービスを利用します。チャット情報は、これらのサービス上に保存・処理されます。当社は、委託先において個人情報およびチャット情報の安全管理が図られるよう、必要かつ適切な監督を行います。

**第５条の３　チャット情報の保存・削除**

1. 当社は、チャットルームが存続する間、チャット情報を保存します。現時点では、チャット情報の保存期間を一律に定めて自動削除する仕組みは設けていません。
2. イベントがキャンセルまたは論理削除等によりチャットルームが読み取り専用となった場合、お客様は当該ルーム内の履歴を閲覧できますが、新たなメッセージの送信はできません。
3. 開催日時を経過した後であっても、当該イベントがキャンセルまたは論理削除されていない限り、チャットルームでメッセージの送受信が可能な場合があります。
4. お客様が注文をキャンセルする等によりイベント参加者から外れた場合、当該イベントのチャットルームへの参加資格を失い、以後当該ルームの閲覧および送信はできません。
5. お客様が送信を取り消した場合、当社はテキストメッセージの本文および添付画像を削除します。ただし、送信取り消しが行われたこと、取り消し時点の表示名、送受信日時等の情報は、ルーム内表示および運用上必要な範囲で残る場合があります。
6. お客様がアカウントを削除した場合、当社はお客様の氏名、メールアドレス、プロフィール画像等の個人情報を削除または匿名化します。ただし、他の参加者とのやり取りの履歴として、当該お客様が送信したテキストメッセージおよび添付画像は、ルーム内に残る場合があります。
7. バックアップ、障害復旧、法令対応、不正利用調査等のため、削除後も一定期間、当社の管理下で情報が残存する場合があります。

**第５条の４　通信内容の取扱い**

1. 当社は、電気通信事業者として、および個人情報取扱事業者として、チャット情報を慎重に取り扱います。
2. 当社は、通常のサービス運営において、チャットのテキストメッセージ本文および添付画像の内容を閲覧しません。
3. 前項にかかわらず、次の場合には、必要な範囲でチャット情報を閲覧し、または削除等の措置を行うことがあります。
   　・法令に基づく開示請求、裁判所、行政機関等からの照会への対応
   　・お客様からの通報、お問い合わせへの対応（お問い合わせ窓口: support@nijuni.jp）
   　・利用規約または法令に違反する行為、不正利用、他のお客様の安全確保のための調査
   　・システム障害の調査および復旧
4. 前項の取扱いにあたっては、当社はアクセス権限の管理、記録の保存その他必要な安全管理措置を講じます。

**第６条　アクセス解析ツールの利用**

本サービスでは、アクセス解析ツール「Google Analytics」を利用しています。Google Analyticsではトラフィックデータの収集のためにCookieを使用しています。このトラフィックデータは匿名で収集されており、個人を特定するものではありません。この機能はCookieを無効にすることで収集を拒否することが出来ますので、お使いのブラウザの設定をご確認ください。この規約に関して、詳しくはGoogle Analytics利用規約をご覧ください。

**第７条　リンク先の個人情報の取扱いについて**

本ウェブサイト及び本アプリには外部のリンクが含まれます。本プライバシーポリシーの適用範囲は本ウェブサイト及び本アプリのみとなりますので、外部のウェブサイト等での個人情報の取扱についてはリンク先ウェブサイトのプライバシーポリシーをご参照ください。

**第８条　個人情報の開示**

当社は、お客様から、個人情報保護法の定めに基づき個人情報の開示を求められたときは、お客様ご本人からのご請求であることを確認の上で、お客様に対し、遅滞なく開示を行います（当該個人情報が存在しないときにはその旨を通知いたします。）。但し、個人情報保護法その他の法令により、当社が開示の義務を負わない場合は、この限りではありません。なお、個人情報の開示を請求される場合には、当社が別途定めた手続きに従って開示手数料をいただく場合がございます。

**第９条　個人情報の訂正等**

当社は、お客様から、個人情報が真実でないという理由によって、個人情報保護法の定めに基づきその内容の訂正、追加又は削除（以下「訂正等」といいます。）を求められた場合には、お客様ご本人からのご請求であることを確認の上で、利用目的の達成に必要な範囲内において、遅滞なく必要な調査を行い、その結果に基づき、個人情報の内容の訂正等を行い、その旨をお客様に通知します（訂正等を行わない旨の決定をしたときは、お客様に対しその旨を通知いたします。）。但し、個人情報保護法その他の法令により、当社が訂正等の義務を負わない場合は、この限りではありません。

**第１０条　個人情報の利用停止等**

当社は、お客様から、お客様の個人情報が、あらかじめ公表された利用目的の範囲を超えて取り扱われているという理由又は偽りその他不正の手段により取得されたものであるという理由により、個人情報保護法の定めに基づきその利用の停止又は消去（以下「利用停止等」といいます。）を求められた場合において、そのご請求に理由があることが判明した場合には、お客様ご本人からのご請求であることを確認の上で、遅滞なく個人情報の利用停止等を行い、その旨をお客様に通知します。但し、個人情報保護法その他の法令により、当社が利用停止等の義務を負わない場合は、この限りではありません。

**第１１条　プライバシーポリシーの変更**

当社は、個人情報の取扱いに関する運用状況を適宜見直し、継続的な改善に努めるものとし、必要に応じて、随時プライバシーポリシーを変更することがあります。 変更後のプライバシーポリシーについては、当社のサイト上での掲示その他分かりやすい方法により告知したときから効⼒を⽣じるものとします。ただし、法令上お客様の同意が必要となるような内容の変更を行うときは、別途当社が定める方法により、お客様の同意を取得します。
